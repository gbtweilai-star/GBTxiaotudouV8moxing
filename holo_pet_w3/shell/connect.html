对话面需要一条「带 token 的 URL」

GBT小土豆V8 桌面壳 · 窗口 dsh-chat · 批次 W9
这不是壳坏了，是 DSH 的设计。
实测（2026-09-23）：GET http://127.0.0.1:3080/ 回 HTTP 401，正文原文 ——
dsh web authentication required; reopen the URL printed by dsh web.
  1. 去看 启动 dsh web 的那个终端，它会打印一条带 token 的完整 URL。
  2. 把那条 URL 粘进下面这个框，按「接上对话面」。
  3. URL 只留在内存，壳不落盘、不回显 —— 返回值只给你 host。

⚠️ 本页故意不提供「自动找到 token」的功能：那等于替你翻凭据。

✅ 在此之前，对话面照常在浏览器里用 —— 本壳没有动过 DSH 一个字节（有守卫脚本为证）。
