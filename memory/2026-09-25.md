## 主人令二：为什么「又把技术给我禁了」→ 授权门分级

  `voice -> {"status":"denied","reason":"需要人工授权（audio_output）"}`，
  而 **`store/auth_grants.jsonl` 是 0 行** ⇒ 15 个作用域全部 fail-closed。
- 🔴 最要命的是**一次性消耗**（`one_shot: True`，用掉即从账本删行）：
  一条 `audio_output` 只够说**一句话**。语音对讲按这个语义物理上不可用。
- 而 README §安全边界 **只写了那道空的门**，还承诺「其余技术能力正常可用」——那句话是假的。

**主人裁决（2026-09-25）**：「改成时段授权：TTL 内可多次用，危险类保持一次性」+「改成人工授权就好了」。

**已落地**（`auth_gate.py`）：

  —— `owner_control` 是我**主动加进去的**：它是总控钥匙，一条顶掉全部缺失作用域，
  变成时段等于一把万能钥匙连开 10 分钟，比它顶掉的每一项各自时段化加起来还宽。
- 其余作用域 = 时段授权：**不从账本删行**，只记 `used` / `last_used_at`；
  审计记 `mode: "window"` + `reuse_count`。这样账本能回答「这张授权被用了几回」。
