### 二、🔴 唯一增量：红线③把「原生栈」的**具体所指**钉死了

```
原生栈 = **触手 + 记忆 + 门禁 + 审计**
  触手 = 执行末端
  记忆 = trace_store / 生命档案 / 知识库
  门禁 = auth_gate / 权限 / 二次确认
  审计 = 独立复核 / 假绿检测 / 护照
```

### 三、为什么必须**逐项**判，不能只看总指纹

```
旧闸 `check_stack_unchanged` 只判**一个总指纹** ——
⇒ 总指纹一样，也可能"**触手换了、审计没换**"互相抵消！

新闸 `check_stack_four` 把四件**逐项**验：
   四件全同    => 放行
   **只有触手变 => changed=['触手']**   ← 总指纹闸抓不到这种单点变化
   **只有审计变 => changed=['审计']**
```

**这是今天"判据粒度"的第 N 次收窄**：从「看总数」到「看每一项」——
同族于 R-H194 的「逐名比对」、R-H214 的「18 不是上限用 as_of」。
