## 一 🔴、抓到的缺陷：安装包会带着主人的桌面截图

```
files:  "eye/**/*"        ← 触手视觉回传整扇窗
实拍:   eye/frames/       12 个文件 · 1.9 MB · f-000.jpg ~ f-011.jpg（**整屏截图**）
        eye/frames.js     3,634 B（描述主人屏幕的帧清单）
```

`.gitignore` 里**早就写着**这两条排除（第 30 轮加的）——
但 **`package.json` 的 `files` 白名单从来没跟它同步过**。
⇒ 打出来的 App **会带着主人的桌面截图分发**。

**为什么以前的门全绿**：

| 已有的格 | 它验什么 | 对这一条 |
|---|---|---|
| `K:globs` | 每条 files 规则**匹配得到实物** | ✅ 绿（`eye/**` 当然匹配得到东西） |
| `K:winfiles` | **每扇窗**都被规则覆盖 | ✅ 绿（`eye` 确实被覆盖了） |

**两格都在验"覆盖"，没有一格在验"进包的是什么"。**
⇒ 新增第 4 格 `K:packsrc`：把整棵树按 electron-builder 的**按序裁决**语义过一遍，
再按「**这是什么**」审计 —— 不是按「规则匹配没匹配到」。

审计面：整屏截图 · 描述屏幕的清单 · `node_modules/` · `__pycache__`/`*.pyc` ·
`.git/` · `desktop.ini`/`Thumbs.db` · `*.log` · 位图资源。

**现读**：`✅ K:packsrc PASS 进包 226 个文件 / 3.7 MB · 无截图/依赖目录/缓存混入`

## 二 🔴、顺带抓到：打包判据共用的 glob 翻译器有 bug

新加的「按序裁决」测试当场判红，追下去发现是**翻译器本身**的问题：

```
链式三步替换：先替「双星+斜杠」→ 再替「双星」→ 最后替「单星」
`a/**`  →  `a/` + 点星  →  第三步把刚生成的那段里的星号又吃一遍  →  `/^a\/.[^/]*$/`
实测：`a/**` 匹配不到 `a/b/c.txt`
```

**为什么一直没露头**：真配置里各条都写成「双星斜杠单星」结尾（`shell/**/*`），
那一步不会走到第三步去；而以「双星」结尾的 `!eye/frames/**` 恰好只用来排除
`frames/` 下的**直接文件**，也没碰上。

⇒ 改成**单趟替换**（一个正则 + 回调，最长优先），并且**预检不再本地抄一份**，
改用 `pack-coverage.cjs` 里那一份 —— 一处定义、预检与测试共用。

加了**回归钉子**：`a/**` 编出来的正则必须能匹配 `a/b.txt` / `a/b/c.txt` / `a/b/c/d/e.txt`。

## 三、这一格补上之后，「打包」这件事还剩什么

| 问题 | 现在能不能答 |
|---|---|
| 包里**会**装进哪些文件 | ✅ 能（`K:packsrc` 现算：226 个 / 3.7 MB） |
| 每扇窗的页面在不在进包清单里 | ✅ 能（`K:winfiles` + 一条测试断言八扇窗全在） |
| 有没有截图/依赖/缓存混进去 | ✅ 能（`K:packsrc` 审计） |
| **装出来的 App 真能跑吗** | ❌ **不能** —— 那要真跑一次 `electron-builder` |

⇒ **剩下的只有最后一条，而它是闸二**（装包/构建要主人点头）。
本轮把"能提前查的全查了"，把真打包那一步留成一个**已经没有任何已知问题**的动作。
