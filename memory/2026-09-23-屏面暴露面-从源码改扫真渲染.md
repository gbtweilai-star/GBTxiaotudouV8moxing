## 一 🔴、为什么**不能**扫源码（这条是本轮的方法论）

要成体系地查"屏上有没有内部信息"，第一反应是全仓 `grep 'C:\'`。**那是错的尺子**：

- **假阳**：只在注释 / 日志格式串里出现的路径，**根本不上屏**，却被算成暴露；
- **假阴**：运行时拼出来的（`path.join(base, name)`）或**从磁盘读进来再渲染**的，
  源码里**一个字都没有** —— h1 那两条路径正是这一类（它们来自 `b.path` / 面板载荷）。

⇒ 唯一可靠的取样面 = **真壳渲染后的 `innerText`**。
`shell/shots.cjs` 现在顺带把每扇窗的 `document.body.innerText` 落成 `<id>.txt`，
判据交给**独立的 Python**（可单测、可复跑，不埋在 Electron 里）。

## 二、判据（每条都写清"为什么这条算暴露"）

| 类 | 命中什么 | 为什么算 |
|---|---|---|
| `win-path` | `C:\…` 盘符绝对路径 | 路径里带**用户名**（主机的私事） |
| `home` | `C:\Users\<用户名>` | 同上，更直接 |
| `loopback` | `127.0.0.1` / `localhost` / `0.0.0.0` | 本机地址；外部看到即内部拓扑 |
| `port-pair` | 地址旁边紧跟端口 | **端口本身不算**（"谁在听"这类面板要靠它）；**地址+端口对**才算 |
| `secret` | `sk-…` / `Bearer …` | 凭据类 |

⚠️ **口径**：本器只报「屏上出现了什么」，**不替你判断该不该出现** ——
每条命中都带上下文片段，由人按上下文裁量。

## 四、修法：掩码做在**渲染出口**上，不是逐个字段

h1 的漏点在 `h1.js`：`["二进制", b.path || "—"]` 与草稿目录那一处，
**直接铺了后端给的 path 字段**。

⇒ 在 `row()`（表格单元）与 `kv()`（键值）这两个**唯一出口**上套 `maskPath()`：

```
C:\Users\ADMIN\AppData\Local\gbt_allinone\bin\h1mcp.exe   →   …\gbt_allinone\bin\h1mcp.exe
```

**为什么做在出口而不是逐个字段**：逐个字段靠人记得，**迟早漏一个** ——
实测就是这么漏的（两处都铺了 path）。收在出口 ⇒ 以后新加字段**自动**被掩码。

**为什么保留末三段**：掩码是"不给内部信息"，不是"不给信息" ——
`…\gbt_allinone\bin\h1mcp.exe` 仍然告诉人这是哪个二进制。

**复扫：7 扇全部 0 命中。**

## 五、扫描器自证（《扫描器自证律》）

只跑"真实样本 → 0 命中"会得出"没问题"的错觉 —— 而 **0 命中既可能是真干净，也可能是尺子瞎了**。

⇒ `--selftest` 给一好一坏两份样本：

| 臂 | 期望 | 实测 |
|---|---|---|
| 对照 A（坏样本） | **必须命中** | **7 条** · 命中类 `home / loopback / port-pair / secret / win-path` |
| 对照 B（好样本） | **必须 0 命中** | **0 条** |

两臂结果不同 ⇒ 判据可判别。

## 六、怎么用（一对命令，默认路径已经对上）

```powershell
cd holo_pet_w3
npm run shots       # 真壳取证：每扇窗一张真图 + 一份 innerText
npm run scan:leak   # 扫屏面暴露（默认读上面那个产物目录）
```

加进 `package.json` 的 `scan:leak` 脚本；实测端到端：
`产物目录 %TEMP%\gbt-shell-shots · 取到 7 扇窗的文字 · 合计命中 0 条`（exit 0）。

⚠️ **没扫 ≠ 干净**：产物目录不存在时它退 **2** 并明说「没找到取样本」，
不许把"没跑"读成"没问题"。

## 七、还剩的硬缺口（下一轮）

1. **数据机制仍不统一** —— 8 扇窗现在有**五种**取数方式：godview 走 IPC 实时、
   exec-deck/code-deck 是**静态快照**（页上写着"重生成命令"）、brain 是**生成的数据文件**、
   eye 是**文件轮询**。第 32 轮统一了"长相"，**没统一"血路"**；
2. **打包仍未真跑**（闸二）—— `K:winfiles` 验的是**配置**不是**产物**，
   产物级验证（包里到底有没有这 8 扇窗）只有真打一次才知道。
