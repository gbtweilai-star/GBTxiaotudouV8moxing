## 5. 「生成端接线」的**精确改动点**（只读摸出来的 · **未动手**）

### 6.1 接线点：链里每一步自带 `cap`（这就是插口）

`gbt_allinone/tools/media_run.py` 的 `CHAINS` 里，每一步是
`{"step":…, "drawer":…, "ext":…, "cap":…}` —— **`cap` 就是那一步用的能力**。现读：

| 链 | 工序 | 现挂的 `cap` | 性质 |
|---|---|---|---|
| `short_video` | **`assets`** | **`ffmpeg.lavfi`** | 🔴 **素材生成那一步现在只是 ffmpeg 合成** |
| `film` | **`shots`** | **`ffmpeg.lavfi`** | 🔴 同上 |
| `short_video` | `edit` / `export` / `publish` | `edit_pipeline.render` / `copy.of_edit` / `media_publish.prepare` | ✅ 已接 |
| `music` | `audio` / `master` / `export` | `audio_mix.mix` / `audio_mix.master` | ✅ 已接 |
| 各链 | `script` `storyboard` `lyrics` `arrangement` `concept` | **`cap: None` + `human: True`** | ✅ **那几步是人写的，框架不代笔**（设计，不是缺口） |

⇒ **接线 = 把 `assets`（短视频）/ `shots`（电影）两步的 `cap` 指向一个真生成器适配器**
（本机现在唯一已验的真生成器 = **ComfyUI 腿**，另一条是 `genrouter` 云腿）。
