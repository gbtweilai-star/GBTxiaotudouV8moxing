## 一 · 品牌三色（白皮书定的，只走 token）

| token | 值 | 名 |
|---|---|---|
| `--gbt-gold` | `#F5B041` | 土豆金 |
| `--gbt-cyan` | `#00E5FF` | 赛博青 |
| `--gbt-violet` | `#7C4DFF` | 深空紫 |

- 品牌渐变：`linear-gradient(90deg, 深空紫, 赛博青, 土豆金)`
- 出处：`holo_pet_w3/window.css:9-11` · `gbt_allinone/docs/holo_pet_UI规格.md §2.1`
- **两条硬纪律**（`holo_pet_w3/tests/test_brand_tokens.cjs`）：
  1. 裸色值只允许出现在 `:root` 的 token 定义块里，块外一律 `var(--gbt-*)`；
  2. 三色 token **声明了就必须被引用** —— R63 实测教训：三色都声明了，`var(--gbt-violet)` 全仓 0 命中，屏上只出了金 + 青两色。声明没人用 = 少一色。
