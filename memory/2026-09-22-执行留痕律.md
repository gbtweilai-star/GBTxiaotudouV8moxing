# 执行留痕律（Owner 亲授 · 2026-09-22）

> Owner 原话：
> **「不管是你还是触手，每次报告必须精细到每一步是怎么执行的都要打印出来，
> 证明没有假执行等一系列的代码错误问题。」**

---

## 一、这条律要杀的是什么

**不是"不诚实"，是"不可证伪"。**

```
报告写「我扫了 8529 个文件」        → 读者**无法验证**，只能选择信或不信
报告写「我跑了 <这条命令>，退出码 0，
        输出头是 <这段>，全文 sha 是 <这个>」  → 读者**能原样复算**
```

**差别不在态度，在可证伪性：**

> **不可证伪的报告里，假执行与真执行长得一模一样。**
> **可证伪的报告里，假执行当场露馅 —— 因为任何人重跑一遍就知道。**

**⇒ 本律是把「严禁假执行」（铁律 6）从"要求"变成"机制"。**

---

## 二、六项（缺一不算"一步"）

| # | 项 | 要求 |
|---|---|---|
| ① | **序号** | 可被引用（"见 STEP 007"），报告内不得跳号 |
| ② | **动作逐字** | 命令/代码**原文**，**不许概括、不许改写**。写成"我检查了安全"是违规 |
| ③ | **启动时刻** | 真实时间戳 |
| ④ | **退出码** | **真实数字**，不是"成功/失败" |
| ⑤ | **产出摘要** | stdout/stderr 的**头与尾** + **sha256**；全文落盘可核对 |
| ⑥ | **判定** | `ok` / `fail` / **`skip`** —— **skip 必须带理由** |

---

## 三、三条不许破

### ① 失败也记，一个字不许省
崩溃、超时、非零退出 —— **全部原样入账**。
**只留成功步骤的报告，比没有报告更坏** —— 它让人以为路是平的。

### ② `skip` 必须带理由，且**不许被读成"没问题"**
```
▸ **没做**，理由: 需要外部病毒库，本机没有
```
**"没扫到" ≠ "扫了没问题"** —— 这两句话混起来就是假执行。

### ③ 摘要不是全文
长输出**落盘** + 记 **sha256**；报告里给头尾。
**让别人能顺着 sha 去核对** —— 这是"可证伪"的落点。

## 四、落点：`gbt_allinone/tools/exec_trace.py`

```python
from gbt_allinone.tools.exec_trace import Trace
t = Trace("这次作业的名字", actor="AI 或 触手名")
t.step("跑六层主机安全扫描",
       ["py", "-3.14", "-m", "gbt_allinone.tools.host_security_scan"])
t.skip("病毒库比对", "需要外部病毒库，本机没有")
t.fact("注册表 Run 项", "读了 HKCU/HKLM\\...\\Run（见 STEP 003 命令）", "0 项")
print(t.report())          # ← 逐步打印，不是概括
t.save()                   # ← 全文落 .scratch/_traces/
```

**它自己就带 `skip()`** —— 因为**"没做"也必须能被记录**，否则人只会记做过的。

## 五、触手也必须遵守（Owner 明确点名的）

**给触手派活时，prompt 里必须写死：**

> **你的报告必须逐步骤列出：你跑了什么命令/读了哪个文件哪一行 → 得到什么读数 → 判定。
> 没做的那一步要写「没做」并给理由。不许写"我检查了""已验证"这类没有动作的句子。**

**判据**：**报告里每一条结论，都要能往上追到一个具体动作（命令或文件:行号）。**
**追不到的结论 = 不算数。**

## 六、与其它铁律的关系

| 铁律 | 本律补的那块 |
|---|---|
| **1 零猜测** | 本律让"看过了"这件事**可被检查** —— 不然"我看了"也是一句话 |
| **4 深度无死角** | 覆盖率闭合（8529/8529）只是第一步；**每一步的过程也要留痕** |
| **5 疑故障追根因** | 留痕让根因**能追** —— 没痕迹时，"根因"只能靠回忆 |
| **6 严禁假执行** | **本律是铁律 6 的执行机制** —— 从"要求诚实"变成"无法作假" |

## 七、一句话

> **说"我做了"没有意义。**
> **说"我跑了这条命令、它这样回的、这是原文落盘的位置"才有意义。**
> **前者要人信我；后者要人验我。要人验我。**
