# AI 音乐生产契约（概念 → 母带）

> 蒸馏自 `bitwize-music-studio/claude-ai-music-skills`（**CC0 公有领域**）。
> 只搬判据与闸；生成在 Suno 上做，本技能不含生成端。

## 0. 链路（每一环都有闸）

```
概念（7 阶段）→ 调研（10 域并行 + 核验）→ 作词 → Suno 提示词
→ 导入分轨逐轨打磨 → 混音母带（-14 LUFS）→ 发布准备（宣传视频 + 社媒文案）
```

## 1. 溯源铁律：**先核验，后作词**

纪实/真实事件类专辑：

1. 主调研员派发到 10 个领域专家（法律 / 金融 / 安全 / 政府 / 新闻 …），各自知道本领域的**一手来源**在哪
2. 一个**独立核验代理**交叉核对所有主张
3. **人工签核**
4. **然后才允许生成歌词**

> 判据：**歌词里的每一条主张，都要能追到一条已捕获、已核验的来源。**

## 2. 歌词闸（13 项）

押韵 · 韵律 · 发音风险 · 视角一致 · 事实准确 —— 以及其余九项。
不通过的处置：扫出**发音风险**要给**音标修正建议**，不是打回了事。

## 3. 生成前闸

- 来源已核验
- 显式标志位已设
- 风格提示词完整
- **艺人名已清**（避免侵权指向）

## 4. 音频 QC（7 项，机器判）

| 项 | 判据 |
|---|---|
| 响度 | 目标 **-14 LUFS**（流媒体标准） |
| 削波 | 不允许 |
| 静音 | 不允许（非艺术意图的） |
| 相位 | 不许反相抵消 |
| 立体声宽度 | 按曲风 |
| 频谱平衡 | 按曲风 |
| 动态范围 | 按曲风 |

**母带要按曲风取 EQ 曲线与响度目标** —— 不是一套参数打天下。

## 5. 结构闸

专辑目录校验 · 文件位置校验 · 内容完整性校验。

## 6. 已知局限（照抄）

- 生成在**第三方 Suno** 上做，插件本身不生成音频
- 需要一个 **PostgreSQL**（宣传/推文内容管理）
- 多轨会话在 Pro 订阅下会撞速率上限（上游建议 Max）
- 上游是 Claude Code 插件（53 技能 / 80+ MCP 工具）；**本技能只蒸馏方法论**
- 上游 CI 带 bandit + pip-audit 静态扫描，Dependabot 每周巡检 ——**本技能不含代码，无此面**
