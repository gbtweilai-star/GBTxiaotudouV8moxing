# 视频生产契约（分镜 → 成片）

> 蒸馏自 `ttalkkaklab/social-flow`。**只搬判据与闸**：生成端、发布端、增长循环一概不含
> （主人 2026-09-21 定：自动发布先不开，链路做到「成片 + 文案」为止）。

## 0. 铁律：分镜阶段**只规划，不生成**

`storyboard` 阶段产出的是**计划**（每个静帧/动效页/片段的提示词、引擎、价格），
**一个像素都不生成**。生成由 `produce` 在被审批之后才发起。

> 意义：退回或废弃的分镜**成本为 0**；审批屏上给的是完整预估，而不是一部分已经花掉、还在继续涨的账单。

## 1. 分镜表结构（四层）

`sequence → scene → shot`，容器是 `data/[频道]/episodes/[选题]/`。

每个 shot 必须写清**为什么这么选**，而不是只写"生成一段视频"：

| 字段 | 取值 | 判据 |
|---|---|---|
| `shot.render` | 静帧（配运镜）/ 3D 角色 / 3D 物件 / 数据图 / 生成视频 | **先读旁白，再决定**；开篇也要走同一套选择 |
| `shot.eyeline` | 视线方向记录 | 一条记录同时驱动：分镜板图标 · MCP 入参 · 源图提示词 · 拍摄脚本。**四处必须同源** |
| `shot.depth` | shallow / deep | 数「观众一次要读几样东西」：一样 → 浅景深并点名锐面；两样以上 → 深景深并从前到后列出 |
| `shot.style` | 例外风格 | **一个镜头要离开全片预设，只能走这个字段**，且必须经人工在 HITL 里批准过 |

**风格是开拍前的选择**：没有风格的分镜板一律打回。

## 2. 三条硬规则（上游明写的用户指令）

1. **不许在视频上画东西**：需要箭头/图形/原理的镜头，改做**一盏打亮的工作台上的 HTML 动效页**；
   当"物件"本身是主体时用真 3D 物件。生成视频只留给**必要的连续动作**，字幕是它唯一的文字。
2. **每一个镜头都要有目的**：读旁白 → 写 `shot.render` → 写选择的理由。复制别人的理由 = 失败。
3. **开场不必是付费视频**：`hook_video` 默认**关**。没有哪个镜头因为"它在开头"就值得付钱。

## 3. 预算闸（花钱之前就拦）

- 生成视频受 **`video_budget_usd`** 约束（默认 $10/集）
- 单张静帧最多占一个镜头（`max_static_ground_seconds` 默认 8 秒）
- 普通节拍上的一图板 = 一句话卡片（`html_plate_max` 默认 2）
- **未知价格直接失败**，不许猜（上游 `cost-report.sh` 对未知价格 exit 1 而不是 0）
- 价格表**每行带证据等级与出处**

## 4. 剪辑契约

装配阶段把每个分镜转场**编译进时间线**：

- 场景在**同一地点或同一时间**发生变化 → 优先 `dip`（过黑淡入淡出）；分镜板在**每个镜头下方**显示效果、时长与理由
- 运动类转场**用的是出点之外的未用帧**，并显式给出源裁剪与旁白边距
- **缺 handle 或卡片选项冲突 → 阻断构建**
- 成片必带：**边界帧校验** + 用于连续性复核的**短播放片段**

## 5. 内容与叙事闸

- **可转发物**：一句能原样被转出去的话（一句话/一个数字/一个判词）。
  **「求转发」不算可转发物，那是请求**。短片里它是收尾镜头的 `shot.share`；缺了分镜板打回。
- **信息句**：把片中的人名去掉后**仍然为真**的一句话 —— 现在时、不填数字、不填人名、不描述画面。
  过去时/带编号/带主角名的一律打回。
- **事实不许扭曲**：时效性数字要**两个独立来源**；是区间就保持区间。
- 每句旁白都要有目的；旁白复核必须**引用具体行**来说意义、推进、回报与落地 —— **数字分数不能豁免失败**。

## 6. 双人审闸（HITL × 2）

1. **分镜审批**（生产前）—— 没审批不许生成
2. **发布审批**（公开前）—— 没审批不许发布

> 发布工具**自身没有复核闸**，一次调用就是一次公开发帖 —— 所以它**只能**躲在发布技能的 HITL 门后面。
> （本工作区主人已定：发布端不启用。）

## 7. 已知局限（上游自述，照抄不美化）

- **文案风格闸是韩语专用**：`check-style.py` 遇到非韩文**退出 4（SKIP）并明说"未检查"**，
  **绝不说"通过"**。非韩文文案必须人工读。
- 拍摄脚本与调研解析器**仅韩语**。
- 分镜复核渲染的**检查条句子是硬编码英文**（未进词典）。
- 端上出图**会打散韩文字形** ⇒ 带文字的帧必须走付费路径。
- 它是 Claude Code 插件形态；本工作区是 DSH ⇒ **本技能只蒸馏方法论，不含可执行插件**。
