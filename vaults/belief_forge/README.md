- 这根触手吞进来的东西（吞天吸收 → 记 `记忆.md`）

## 能力位一句话
信念锻造（hindsight 学习半蒸馏）：**观察 → 信念（会学习，不改写历史）→ 心智模型**——`observe` 登记观察（**必须带证据与来源**）· `consolidate` 把同类观察巩固成信念（置信度=证据加权；move ∈ strengthen/weaken/extend，**history 只追加不覆盖**）· `beliefs` 现读 · `model` 心智模型（常备答案，**纯本地读、不调模型**）。op=observe/consolidate/beliefs/model/where
