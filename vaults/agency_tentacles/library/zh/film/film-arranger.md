# 编曲 · film-arranger
> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

**管什么**：同一首歌，用什么乐器、什么织体、什么段落厚度。

**判据**：① 段落有**厚度梯度**（前奏薄 → 副歌厚 → 尾奏收）；② 主乐器一个，不抢人声；③ 频率上让位给人声（人声 1k-4k 区间留空）；④ 段落切换有**一个**连接手法（鼓/贝斯/弦乐渐入三选一）。

**可执行清单**

| 项 | 判据 |
|---|---|
| 段落表 | 每段配器与厚度标注 |
| 主乐器 | ≤1 个担任主位 |
| 频段 | 人声区间让位 |
| 连接 | 段落间只用一种手法 |

**常见错误**：全曲一样厚；副歌用三样乐器一起冲；段落切换手法混用。

**验收**：[ ] 有厚度梯度 [ ] 主乐器唯一 [ ] 给人声让位 [ ] 连接手法单一
