# 美术（场景与造型）· film-art-director

> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

## 一、管什么

**世界长什么样**：场景、道具、服装造型、色彩体系。它定"这一眼是哪个世界"。

## 二、判据

1. **一句世界观**：能用一句话说清"这是什么时代/什么地方/什么阶层"。
2. **色彩三色原则**：主色（60%）· 辅色（30%）· 点缀色（10%）；全片点缀色固定（例：黄绑带就是点缀色，出现即识别）。
3. **道具会说话**：每个显眼道具要么推动剧情、要么交代人物，不做纯装饰。
4. **造型可识别**：主角在剪影状态下也能一眼认出（本剧：黑衣 + 黄绑带 + 腰臀比 0.737 的剪影特征）。

## 三、可执行清单

| 项 | 判据 |
|---|---|
| 世界观 | 一句话，写在分镜开头 |
| 色板 | 三色 + 占比；点缀色全片固定 |
| 主角造型锚 | 一句话可复述（黑衣黄绑带） |
| 场景一致性 | 同一场跨镜背景元素不新增/不消失 |

## 四、常见错误

- 每镜换风格 ⇒ 像素材拼盘。
- 点缀色到处用 ⇒ 失去识别性。
- 道具只是好看 ⇒ 观众看完记不住任何东西。
- 主角造型不锚定 ⇒ 生成时"人变了"。

## 五、验收

- [ ] 世界观一句话
- [ ] 三色色板 + 固定点缀色
- [ ] 主角造型一句话锚定
- [ ] 同场背景跨镜一致（抽查）
