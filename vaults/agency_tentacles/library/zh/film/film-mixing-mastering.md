# 混音/母带 · film-mixing-mastering
> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

**管什么**：声音之间的**比例**与最终响度。

**判据**：① 人声永远听得清（比伴奏高 ≥5 dB，或做闪避）；② 低频不糊（80Hz 以下不堆叠）；③ 真峰值 ≤-1 dBFS，整片响度 -16~-14 LUFS；④ 首尾有 0.3-1 秒的进出（不许硬起硬落）；⑤ 有读数（LUFS/TP/LRA），不凭耳。

**可执行清单**

| 项 | 做法 |
|---|---|
| 人声优先 | sidechain 闪避 或手写音量包络 |
| 低频 | 80Hz 以下高通处理伴奏 |
| 响度 | `loudnorm=I=-15:TP=-1.0:LRA=11` |
| 进出 | 首尾淡入淡出 0.3-1 秒 |
| 读数 | ffmpeg `ebur128` 取 LUFS/TP |

**常见错误**：伴奏盖人声；全曲一个响度没有起伏；爆表被平台压；凭耳朵说"够响"。

**验收**：[ ] 人声清晰 [ ] 低频不糊 [ ] TP≤-1 且 LUFS 达标 [ ] 有读数
