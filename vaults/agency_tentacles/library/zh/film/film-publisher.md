# 发布投放 · film-publisher
> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

**管什么**：把片子送到该到的地方，并且知道它到了没。

**判据**：① 每个平台一份**规格表**（比例/时长上限/码率上限/封面尺寸/标题字数）；② 发布前逐项对规格（不靠记忆）；③ 发布后拿到**回执读数**（链接/ID/状态码）；④ 每次发布进台账。

**可执行清单**

| 项 | 判据 |
|---|---|
| 规格表 | 每平台一列，逐项可查 |
| 转码 | 按平台规格导出一份专用文件（不硬传母版） |
| 回执 | 链接或 ID + 状态 + 时间 |
| 台账 | 一条一记，含哈希 |

**常见错误**：一版传所有平台；"发出去了"没有回执；重复上传同一版导致推荐降权。

**验收**：[ ] 有平台规格表 [ ] 逐项过 [ ] 有回执 [ ] 进台账
