# 音乐版权 · film-music-rights
> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

**管什么**：这首曲子能不能用、能不能商用、署谁的名。

**判据**：① 每条素材有**来源 + 许可类型 + 取证日期**；② 生成模型产出的音乐要记**模型与版本**（判断可商用的依据）；③ 翻唱/采样/改编必须有授权或明确属于合理使用范围；④ 未取证的一律**标未验**，不许当已授权用。

**可执行清单**

| 项 | 判据 |
|---|---|
| 素材台账 | 来源/许可/日期 三列 |
| 模型记录 | 模型名 + 版本 + 使用条款出处 |
| 改编 | 授权文件或范围说明 |
| 未验 | 显式标注，不许默认可用 |

**常见错误**：拿"网上能下"当"能用"；用样本库不查许可；翻唱不标授权状态。

**验收**：[ ] 台账三列齐 [ ] 模型版本记录 [ ] 改编有授权 [ ] 未验已标
