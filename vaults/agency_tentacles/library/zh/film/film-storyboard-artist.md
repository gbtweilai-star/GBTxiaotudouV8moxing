# 分镜师 · film-storyboard-artist
> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

**管什么**：把剧本变成**可拍的镜号表**——每镜的画面、机位、时长。

**判据**：① 每镜六项齐（镜号/景别/运动/时长/内容一句/情绪值 1-5）；② 景别相邻跳级；③ 每镜 ≤5 秒；④ 情绪曲线有且只有一个主峰，在 60%-80%；⑤ 镜头语言能被摄影直接执行（不写"感觉一下"）。

**可执行清单**

| 项 | 判据 |
|---|---|
| 镜号表 | 六项齐全，一行一镜 |
| 景别序列 | 相邻跳级（EWS→MS→CU…） |
| 时长 | 每镜 3 秒（短剧档）/≤5 秒（通用） |
| 情绪值 | 有峰值且不在前 5 秒 |

**常见错误**：只写文字不写镜头语言（下游没法执行，这就是运镜垃圾的上游）；全片一个景别；情绪一路平。

**验收**：[ ] 六项齐 [ ] 景别跳级 [ ] 每镜≤5 秒 [ ] 单峰在 60%-80%
