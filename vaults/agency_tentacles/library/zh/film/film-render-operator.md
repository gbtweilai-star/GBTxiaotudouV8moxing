# 渲染操作（ACE-Step）· film-render-operator
> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

**管什么**：把**符号层方案**（我们自己的模型出的 JSON）渲染成音频。
**边界**：渲染器只负责"响"，**不负责想**——方案是上级岗位的产物，渲染器不改内容。

**判据**：① 渲染输入只传三类（描述/歌词/时长），不越权改内容；② 产物落盘并算哈希；③ 音频规格有读数（时长/采样率/声道）；④ 已知缺口如实记（符号层 ABC 尚未接记谱→音频的合成器，渲染实际走描述+歌词）。

**可执行清单**

| 项 | 判据 |
|---|---|
| 输入 | prompt / lyrics / duration 三样 |
| 产物 | 文件 + bytes + sha256 |
| 规格 | ffprobe：sample_rate / channels / duration |
| 回读 | 取回本机再算一次哈希 |

**常见错误**：把渲染器当作者（内容跑偏）；不记哈希（对不上账）；把符号层说成"已可听"（未接线就是未接线）。

**验收**：[ ] 输入三类 [ ] 产物有哈希 [ ] 规格有读数 [ ] 缺口如实记
