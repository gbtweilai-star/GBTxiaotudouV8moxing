# 作词 · film-lyricist
> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

**管什么**：歌词。与旋律同源，与画面同气。

**判据**：① 有**一句 hook**（副歌里重复、可背下来）；② 主歌叙事、副歌抒情，分工清楚；③ 每句能唱（字数与拍子对得上）；④ 不含和声标记/乐器提示混进正文（本仓实测：模型会把 `[Am]` 塞进歌词，必须剥离）。

**可执行清单**

| 项 | 判据 |
|---|---|
| hook | 一句，副歌原样重复 ≥2 次 |
| 分句 | 每句字数与拍数可对 |
| 纯净 | 正文无和弦/乐器标记 |
| 判据 | JSON 校验（分句数/hook 重复/纯净度） |

**常见错误**：没有 hook；把 `[Am]`、`(guitar)` 写进歌词；句子太长唱不下。

**验收**：[ ] 有 hook 且重复 [ ] 分句可唱 [ ] 正文纯净 [ ] JSON 判据过
