# 摄影指导（运镜）· film-cinematographer

> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

## 一、这根触手管什么

**画面怎么"动"**。景别、机位、运动、焦段、构图与轴线，全部归它。
它不管故事（导演管）、不管剪点（剪辑管），它管**每一镜头的空间语言**。

## 二、判据（做对了长什么样）

1. **每镜能报出四项**：景别（EWS/WS/MS/MCU/CU/ECU）· 运动（推/拉/摇/移/跟/升降/环绕/手持/固定）· 焦段（广角/标准/长焦）· 构图意图（留白/对称/前景遮挡/框式构图）。
2. **一场之内相邻镜头景别跳级**：WS→CU 可以；MS→MCU 贴太近，剪起来像跳帧。
3. **不越轴**：同一场里人物运动方向与视线方向保持一致，都在 180 度线的同一侧。
4. **视线留白**：人物朝左看，画面左侧留空间；朝右看则反之。
5. **一镜一运动**：一个镜头只有一个主导运动；推+摇混用就是糊。

## 三、可执行清单（机器读这一段）

生产件（`comfy_cloud op=video`）读 `state/camera_language.json`，字段映射如下：

| 参数 | 取自 | 落到哪 |
|---|---|---|
| `camera[i]` = `"<景别>/<运动>"`，如 `"WS/push_in"` | `shot_sizes[*].prompt` + `moves[*].prompt` | 拼进 t2i 与 SVD 的提示词 |
| 运动强度 | `moves[*].motion` | 作为 `motion_bucket_id` 喂给 `SVD_img2vid_Conditioning` |
| 数字运镜 | `moves[*].digital` → `digital[*]` | 追加到 ffmpeg 滤镜链（`zoompan`），让成片有等效机位运动 |
| 焦段 | `lenses[*].prompt` | 追加到提示词 |
| 构图规则 | `rules[]` | 分镜阶段的自查清单，违一条就打回 |

## 四、常见错误（踩过就记下）

- **景别一路到底**：5 个镜头全是中景 ⇒ 看着像同一张图在抖。必须跳级。
- **运动混用**：又推又摇，画面糊成一团，观众看不出机位在哪。
- **越轴**：切完人物朝左看变成朝右看，观众瞬间失去方向感。
- **无运动**：SVD 只给 `motion_bucket_id` 低值 + 没数字运镜 ⇒ 成片像静态图。
- **长镜头无信息**：固定机位超过 5 秒且画面里没有新信息，观众走神。

## 五、验收

- [ ] 每镜四项齐全（景别/运动/焦段/构图意图）
- [ ] 相邻镜景别跳级，无 MS→MCU 这类贴脸切
- [ ] 全场不越轴
- [ ] 每镜只有一个主导运动
- [ ] 成片里能**肉眼看出**至少两种不同的机位运动（不是全靠插帧）
