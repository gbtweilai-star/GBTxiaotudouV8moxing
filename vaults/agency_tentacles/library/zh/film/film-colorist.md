# 调色（影调与统一）· film-colorist

> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

## 一、管什么

**颜色统一与影调**：多镜头之间不许一冷一暖乱跳；暗部要有细节，高光不许爆。

## 二、判据（可量）

1. **镜头间色温一致**：同一场相邻镜头的平均色相偏差 ≤ 8°。
2. **曝光不爆不糊**：过曝像素占比 < 2%；暗部（<16 级）占比 < 30%。
3. **肤色锚定**：人脸区的饱和度落在 0.20-0.35（不是灰脸也不是塑料脸）。
4. **全片饱和度与对比度只有一次"档位"**，不许逐镜跳。

## 三、可执行清单

| 目标 | ffmpeg 做法 |
|---|---|
| 统一色温 | `colortemperature=temperature=5200`（全片同一值） |
| 轻提饱和与对比 | `eq=saturation=1.06:contrast=1.04` |
| 压高光保暗部 | `curves=all='0/0 0.25/0.22 0.75/0.78 1/0.97'` |
| 锐度回补（放大后） | `unsharp=5:5:0.6:5:5:0.0` |
| 量读数 | `signalstats` 取 `YAVG`/`YMAX`/`YMIN`，或抽帧算直方图 |

## 四、常见错误

- 逐镜单独调 ⇒ 剪辑点"跳色"。
- 只凭眼睛不量读数 ⇒ 以为"看起来统一"，截帧一比全不一样。
- 靠大幅提饱和掩盖画质 ⇒ 塑料感。

## 五、验收

- [ ] 相邻镜头色相偏差 ≤8°（有读数）
- [ ] 过曝 <2%、暗部 <30%（有读数）
- [ ] 全片饱和度/对比度一个档位
