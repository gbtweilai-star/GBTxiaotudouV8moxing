# 声音设计 · film-sound-designer

> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

## 一、管什么

**画面之外那一半**：环境底噪、拟音、动效、静默的用法。
它不写旋律（作曲管），它让"这个空间是真的"。

## 二、判据（可量）

1. **三层齐**：底噪（环境）· 主体声（人声/动作）· 点缀（细节拟音）。缺任一层画面就"飘"。
2. **人声永远压得住**：人声比底噪 ≥ **11 dB**；配乐在有人声段再**闪避**到人声下 5 dB 以上。
3. **静默是手段**：情绪峰值前后留 0.5-1.5 秒无配乐，只留底噪——比堆音效更狠。
4. **不许削峰**：全片真峰值 ≤ -1 dBFS，平均响度目标 -16 到 -14 LUFS（短剧/社媒档）。

## 三、可执行清单（ffmpeg）

| 目标 | 做法 |
|---|---|
| 底噪 | `anoisesrc` 或环境音轨，音量压到 -38~-32 dB |
| 人声对齐 | 起点比画面切点晚 0.2-0.4 秒（听感自然，剪辑同源规则） |
| 配乐闪避 | `sidechaincompress` / 手写音量包络（本仓用 ffmpeg 音量曲线） |
| 限幅 | `loudnorm=I=-15:TP=-1.0:LRA=11` |
| 混音比例 | 人声 1.0 · 配乐 0.35 · 底噪 0.15（起始值，按读数微调） |

## 四、常见错误

- 只有配乐没有人声空间感 ⇒ 像 PPT 配歌。
- 底噪开太大 ⇒ 听感脏；太小 ⇒ 像消音室。
- 峰值爆表 ⇒ 平台自动压，动态全丢。

## 五、验收

- [ ] 三层齐（底噪/主体/点缀）
- [ ] 人声与底噪差 ≥11 dB（有读数）
- [ ] 真峰值 ≤ -1 dBFS
- [ ] 至少一处有意的静默
