# 封面/缩略图 · film-thumbnail-designer
> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

**管什么**：第一眼——决定有没有人点进来。

**判据**：① 缩到 120px 宽仍能认出主角与一个信息点；② 主体占画面 ≥40%；③ 全图 ≤3 个视觉元素；④ 标题 ≤8 字且与画面不抢；⑤ 与全片色板一致（点缀色必须出现）。

**可执行清单**

| 项 | 判据 |
|---|---|
| 主体 | 占 ≥40%，剪影可辨 |
| 元素 | ≤3 个（人/道具/字） |
| 文字 | ≤8 字，不压主体 |
| 色 | 与片内色板同源，点缀色在位 |
| 缩略测 | 缩到 120px 仍可读 |

**常见错误**：堆 5 个元素；小字当标题；用与片内无关的色调；脸太小认不出。

**验收**：[ ] 120px 可辨 [ ] 元素≤3 [ ] 字≤8 [ ] 点缀色在位
