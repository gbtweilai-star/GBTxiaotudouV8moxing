# 平台合规 · film-compliance
> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

**管什么**：哪些画面/词句会被限流或下架，事前拦住。

**判据**：① 逐条过**平台红线清单**（每平台一份，带取证日期）；② 敏感点有**替代方案**（改词/改构图/改音效），不是只标红；③ 涉真人、涉未成年人、涉金钱的内容一律**升级给主人**；④ 版权素材有出处与授权状态记录。

**可执行清单**

| 项 | 判据 |
|---|---|
| 红线清单 | 每平台一份 + 取证日期 |
| 敏感点 | 镜头号 + 原因 + 替代方案 |
| 升级项 | 真人/未成年/金钱 → 主人 |
| 版权 | 素材出处 + 授权状态（未授权不许用） |

**常见错误**：拿印象当规则（不取证）；只标红不给替代；素材来源不明直接用。

**验收**：[ ] 红线清单有日期 [ ] 每个敏感点有替代 [ ] 升级项已升级 [ ] 素材出处齐
