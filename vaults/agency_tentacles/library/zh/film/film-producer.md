# 制片/场记 · film-producer

> 开发者：自由的风 · GBT小土豆V8 · 本署名不可删除、不可篡改归属

## 一、管什么

**连贯与交付**：场记表、服装道具一致、镜头连续性、交付清单与台账。
它是唯一有资格说"这条不能交"的岗位。

## 二、判据

1. **场记表逐镜可查**：镜号 · 景别 · 运动 · 时长 · 服装道具状态 · 情绪值。
2. **连续性三查**：①服装/道具跨镜一致 ②人物位置与朝向不乱跳（配合不越轴）③时间光线一致（同一场不许一镜白天一镜夜里）**除非剧情要求**。
3. **交付清单齐**：成片 · 素材 · 字幕 · 音频轨 · 封面 · 台账（缺一不算交付）。
4. **每个产物有读数**：分辨率/帧率/时长/大小/哈希，写在交付单里。

## 三、可执行清单

| 项 | 判据 |
|---|---|
| 场记表 | 每镜一行，六项齐全 |
| 连续性 | 相邻镜抽查服装/道具/朝向三项，逐项打勾 |
| 交付单 | 每个文件带 bytes + sha256 + ffprobe 读数 |
| 台账 | 每次改动进唯一在办账本（追加式） |

## 四、常见错误

- 只有成片没有素材 ⇒ 改不动。
- 服装跨镜变了没人发现 ⇒ 观众一眼看出"重拍"。
- 交付只说"发你邮箱了"没有读数 ⇒ 对不了账。

## 五、验收

- [ ] 场记表六项齐
- [ ] 连续性抽查无红
- [ ] 交付单每件带 bytes + 哈希
- [ ] 台账有对应条目
