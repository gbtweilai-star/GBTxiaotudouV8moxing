# datakit · 触手记忆库

> 本库是触手 `datakit` 的**独立永久记忆**。互通往返见页尾。

## 这本库记什么
- 这根触手吞进来的东西（吞天吸收 → 记 `记忆.md`）
- 它的能力面与判据（有的话写 `能力.md`）
- 它踩过的坑与修法（教训只追加，不改历史）

## 能力位一句话
本地数据工具（**只读**）：html→markdown · html→表格结构 · xlsx 字节→JSON · JSON 美化/排序 · 多段 CSV 合并（`op` 分派，见 `tools/datakit.py` 的 OPS）。🔴 **结果从返回里给、不落盘** ⇒ 作用域天然为空，**不需要也不该改 `policy.py`**。**为什么不给落盘版**：一个会写盘的新能力位若 policy 里没有分支，就是**绕过门**；`policy.py` 是安全文件，只有主人能改 —— 要落盘请他加分支。
