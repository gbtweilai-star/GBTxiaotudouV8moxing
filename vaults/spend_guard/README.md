## 能力位一句话
花费守卫（paperclip 成本治理蒸馏）：**按维度追踪调用与 token + 阈值三态判定**——`ledger` 从 key_gateway 真账按日/按源聚合（token 记多少报多少，**免费通道 0 就报 0**，不按价目表脑补）· `policy` 阈值策略（数据文件，主人可改；缺则如实标"默认"）· `verdict` 三态 ok/warn/stop（**只判定不拦**——拦仍走现有门；账读不到 ⇒ unknown ≠ ok）。op=ledger/policy/verdict/where
