## 能力位一句话
**环形自动化上下文**（主人令 2026-10-11「设计一个圆型的自动化上下文，一直保持上下文长度却不会顶到溢出；另一边直接进数据库，需要查秒查」）：把上下文做成**一屏环**+**全量落库**+**秒查**。① 环形窗口：window() 恒定 ≤ window_chars，滑进来的进来、最老的挤出去 ⇒ **永不溢出**；② 溢出落 SQLite FTS5（seq 单调，只追加）⇒ **一条不丢**；③ recall(q,k) 走 FTS5 + CJK 兜底 ⇒ **秒查**（实测 60 轮/7200 字，查已滑出的老内容 2.97ms）。铁律：挤出≠删除（落库失败就不挤出）· 长度恒定 · 只追加 · 一屏给模型、全量给查询。实测治的病：框架 system 13480 字 + max_tokens 2000 顶爆端点窗口 ⇒ 502。op=stats/window/push/re
