## 能力位一句话
**确定性直达（主人令 2026-10-13）**：给能力名即**指名派单、不猜**；执行一律经**统一门 run_task**
（权限门 / 审计 / 钢印 / 禁用名单照旧生效；危险动作 / 付款由**护栏 + 人工审核**兜底）。
**不给名字一律拒（fail_closed）**——不许替她猜一个去跑。
入参：`kind`=能力名、`payload`=给它的入参。对位件：`gbt_allinone/tentacle/express_bridge.py::direct`。

## 为什么要有它（砍掉那个不定因数）
`route()`（会猜的那条）实测判歪过：把「看看屏幕上写了什么」判成 `codex_status`；
语义层还**偷偷调外部 LLM**（耗 6 秒 · `provider: agnes`）；危险位 `data_hijack` 甚至排到过第一。
⇒ 主人令：**器官是她的，她知道要哪个**；不确定的"理由"不该夹在她和执行之间。
⇒ 主路 = `direct()`（确定性）；`route()` 降级为**可选加速**，且它给的是**提名，不是决定**。
