# 声音优化交付说明 — Voice Mouth v3

## 升级内容

从 Windows SAPI（机械音）升级到 **edge-tts**（微软神经网络音色），三引擎自动降级：

```
edge-tts（晓晓/晓伊/云希，免费云端，0.8s 生成，自然度跃升）
   ↓ 失败自动降级
SAPI（本地兜底，永不掉线，机械音保底）
```

## 五种风格

| 风格 | 音色 | 适用 |
|------|------|------|
| lively | 晓晓（活泼少女）+20% 语速 | 日常互动、撒娇 |
| professional | 晓晓 +10% | 工作播报（默认） |
| warm | 晓伊（温柔少女） | 关心、陪伴 |
| male | 云希（阳光男声） | 可选 |
| narration | 晓涵（知性旁白） | 可选 |

## 实测

- 三风格自测 3/3 成功（0.8-0.9s/句，mp3 留档 voice_cache/ 可回放）
- 五维全链路：嘴维用新嗓子播报 GLM 总结「任务圆满搞定！桌面焕然一新，物品归位，灰尘拜拜～」
- 过载兜底：GLM 1305 重试 + 模板兜底，语音永不失声
