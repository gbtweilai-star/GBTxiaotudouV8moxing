## ⑤ 必须统一的项（按优先级）

### P0 · 公开展示前必须修
1. **exchange.html 品牌名口径**：`<title>GBT Exchange — 数字资产兑换</title>`(L6) 与 meta(L7) 统一为「GBT小土豆量化收益平台」口径（如 `<title>GBT小土豆量化收益平台 · 数字资产兑换</title>`）。
2. **index.html 费率漏项**：补「法币→币 10%」。当前 L63 仅「币→币 1.5% · 量化收益 5%」，L81 仅「1.5%」，缺 10%。
3. **exchange.html 费率漏项**：补「量化收益 5%」或显式声明该值不在本页适用范围。当前仅 1.5%/10%。
4. **messages.html 免责声明 + 18+/区域合规全缺**：与 index/wallet 口径补齐。
5. **exchange.html 免责声明不完整**：L232 仅「连接钱包即代表您已阅读并同意平台条款 … 18+」，缺 index/wallet 的完整免责段（要约/风险/年满18/地区法规）。

### P1 · 统一性缺陷
6. **免责声明归并为单一权威版本**：现 3 套变体（A / A+补句 / B / C）+ 1 缺。建议抽出统一免责段落，所有页面逐字复用（index 与 wallet 差异仅差一句落款，应统一）。
7. **meta description 口径统一**：messages 补写；并统一句式（site_* 用冒号体，index/wallet/exchange 用间隔号体），至少同组（app 组 / 官网组）内部一致。
8. **导航组件不统一**：index 用卡片网格无底部 tabbar；wallet/exchange 用同名 class 底部栏；messages 用**行内 style** 复刻同一栏（L337–340）。应抽成共享组件/同名 class，保证四入口视觉与结构一致（"首页"在 index 上自我指向，可接受）。
