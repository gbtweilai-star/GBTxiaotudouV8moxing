# 综合设计定稿（S3 汇总）· gbt-public-showcase

## 核心判断
四份审计高度一致：**里子厚、门面薄**。事实型文案+单据化+费率透明是真资产；
门面 index.html 是"内部工具箱"（6 等宽卡+emoji 图标+渐变标题+方向预览外露），
且存在死链（terms）、费率漏项（缺 10%）、跨页视觉断档三大硬伤。

## 定稿设计方向：深蓝+鎏金「静谧奢华 · 账本质感」
1. **结构**：Hero(主张+CTA+信任条) → 数据带(可核验指标) → 三个产品入口(非对称:1大2小) → 机制三步(编号行) → 官网入口(单行,收编 A/B/C) → 合规章 → 免责页脚
2. **色彩纪律**：金=等级色只用在 1px 结构线/关键数字/主CTA(像素≤5%)；深蓝 3 档；青金只做数据语义；全页发光元素≤1
3. **反俗套**：零 emoji 图标（自绘 SVG 线性图标）、零渐变文字、零循环动画（入场一次≤600ms）、零空心 KPI、零药丸滥用；1px 发丝线做层级
4. **排版**：衬线大标题（系统衬线栈）+ 无衬线正文 + 等宽数字；4 级字号阶梯；正文≤38字/行
5. **合规当一等公民**：18+/区域合规/风险中性表述在首屏下方成条呈现，不藏页脚
6. **Hero 视觉**：gbt_hero_facade.jpeg（1600×900, 深蓝+金铜质感, 左侧负空间放文字）
