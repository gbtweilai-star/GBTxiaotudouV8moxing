## ① AI 生成网页「俗套黑名单」（2025–2026）

判定标准：**一个视觉手法，如果它在 2023 年后被非设计师反复无差别套用，以至于读者看到它就能反推出"这是 AI / 模板做的"，那它就是俗套。**
俗不等于丑——俗是**可预测**。可预测就是死。

| # | 套路 | 为什么俗（锋利版） | 怎么避免（可执行） | 本门面是否踩雷 |
|---|---|---|---|---|
| 1 | **紫色渐变**（`#8B5CF6→#EC4899` 一类 violet/fuchsia 对角线渐变） | 它是「AI 默认皮肤」。紫渐变 = Tailwind v3 模板 + Vercel/Linear 跟风者的通用指纹，出现即宣告"我没有品牌色概念"。紫还自带"廉价 Web3 资金盘"的坏联想。 | 先定品牌主色，再让渐变**只用同色系明度差**（如 `#0B1E33→#132C49`）；**永远不跨色相做装饰渐变**。跨色相渐变只允许出现在"光"上（环境辉光），不允许出现在"面"上。 | ✅ 未踩。用的是深蓝+青+金，没有紫。**这是本组最大的正确决策。** |
| 2 | **玻璃拟态滥用**（`backdrop-filter: blur()` 撒满卡片、导航、弹窗、按钮） | 玻璃是"信息层级"的烟雾弹。真正需要景深的地方只有 1–2 处（浮层/模态），把它铺到每一张卡上，等于用 12px 模糊掩盖"这些卡片根本没有层级差异"。而且玻璃在深色底上会吃掉对比度，反而更糊。 | 全站 `backdrop-filter` **≤ 2 处**，且必须满足"该元素确实悬浮在其他可读内容之上"（模态、吸顶导航）。卡片一律用**实色面板 + 1px 描边**代替，描边比模糊更贵气。 | ❌ 踩。`exchange.html` 用了 5 处 blur(12/8/6px)，`wallet_v2.html` 3 处，`site_a/c` 各 1 处。exchange 已经属于滥用。 |
| 3 | **过度发光 / 霓虹**（双层 `box-shadow` 光晕、`text-shadow` 泛光、`0 0 12px` 描边光） | 发光是"深色底上的廉价补偿"：设计师怕深色太空，就往元素上打光。结果是所有东西都在尖叫，读者**没有一个焦点**。霓虹尤其危险——它把金融/合规产品拉进夜店语境，直接摧毁信任感。 | 全站**只保留 1 层辉光**，且只给"当前唯一主行动点"。判定式：如果页面同时有 ≥2 个元素在发光，就是失败。`text-shadow` 泛光（≥20px 模糊）**直接禁用**。 | ❌ 重度踩。`exchange.html` 有 `0 8px 40px rgba(56,225,255,.35), 0 0 80px rgba(56,225,255,.15)` 双辉光按钮；`wallet_v2.html` 13 条 shadow 里多数带青色光晕；`site_c.html` 有 `0 0 12px rgba(53,224,255,.7)` 真·霓虹点。 |
| 4 | **千篇一律的 SaaS 网格卡**（2×3 / 3×2 等宽卡片，每张 = 图标 + 标题 + 两句描述） | 这是"我不知道怎么表达信息层级，所以平均分配"的形状。等宽卡片把**重要和不重要拉平**——而一个金融门面最重要的能力恰恰是"说清主次"。它的孪生兄弟是 KPI 三连（`已注册钱包 / 累计兑换 / 费用收入` 各配一个大数字）。 | 卡片**禁止等宽**：用 1 张大卡（主能力）+ 2 张窄卡（次能力）的非对称栅格。或者干脆不用卡——用**编号行**（`01 量化交易 —— 描述`）配 1px 分隔线，这是"文档质感"，不是"模板质感"。 | ❌ 踩。`index.html` 是标准 6 卡网格；`site_a/b/c` 是 `.svc` 三卡 + `.card.feature` 四卡；`exchange.html` 三连 KPI 大数字。 |

| 7 | **悬浮阴影过重**（`0 24px 60px rgba(0,0,0,.5)` 级别的"卡片飘起来"） | 阴影本该模拟真实光照，但模板作者把它当装饰，越加越大、越加越黑。在深色底上，大黑影 = 脏边；在浅色底上，大黑影 = 廉价电商。"飘起来"的卡片暗示**可点击/可拖动**，但门面卡根本不可交互，这是欺骗性动效。 | 阴影**≤ 2 层**、模糊半径 ≤ 40px、透明度 ≤ .30。深色底上**优先用内阴影/1px 高光边**做体积，而不是外投影。浅色底上，静态卡用 ≤ .12 的柔影，只有模态才允许更重。 | ❌ 踩。`site_a` `0 30px 80px rgba(0,0,0,.45)`、`site_c` `0 34px 90px rgba(0,0,0,.5)`、`0 24px 60px rgba(0,0,0,.55)`，均已超线。`site_b` 唯一合格（`.14` / `.15` 两条柔影）。 |

| 9 | **渐变文字滥用**（`background-clip: text` 上色标题） | 渐变文字是"标题不够有力，所以给它上了层糖纸"。它同时破坏可读性（渐变中段对比度不足）、破坏无障碍（屏幕阅读器无碍但低视力用户读不清）、并且在深色底上极易糊成一团。当它和发光叠加，就是俗套的完全体。 | 标题用**单色 + 字重 + 字号**立威。全站 `background-clip:text` **≤ 1 处**，且强度必须极低（同色系明度差 ≤ 20%）。鎏金标题（`金色→白→金色`）是**绝对禁区**——那是喜糖盒。 | ❌ 踩。`index.html` 4 处（含 `txt→cy→gold` 三色渐变 h1）、`exchange.html` 4 处、`wallet_v2.html` 4 处（含 `gold→#fff→gold` 鎏金扫光）。`site_a/b/c` 干净，是范本。 |
| 10 | **左图标右文字列表堆砌**（每行都是 `[24px 图标] + 粗标题 + 灰描述`，一列到底） | 当所有条目都长成同一形状，读者的眼睛会**失去扫描锚点**——10 行等重信息等于 0 行信息。它还是"内容不够、用图标凑密度"的表现。 | 同屏同类"图标+文字"行 **≤ 4 条**。超过就换形：① 两列文档条（`术语 — 值`）② 编号行带 1px 分隔线 ③ 只在首条给图标，其余用缩进对齐。 | ❌ 踩。`index.html` 6 张卡均为 `ic`(24px emoji) + 标题 + 描述；`exchange.html` 钱包列表 `wallet-ic + wallet-name + wallet-desc` 同构重复。 |

**黑名单附加项（本组未命中但高度相关，值得一并封杀）**
- **英文 eyebrow 夹中文标题**（`Services` / `Transparent Fees` 小字压在中文 H2 上）：这是"假装国际化"的模板肌肉记忆。中英并置本身没错，但**必须真有双语受众**，且英文必须是正式译名而非机翻片段。本项目 7 个 kick 标签全部是英文，属于机械套用。
- **滚动揭示动效 `.rv` + `.d1~.d4` 阶梯延迟**：当每个区块都"淡入上浮"，页面就变成了 PPT。全站揭示动效 ≤ 3 个区块。
- **圆形 999px 药丸按钮成灾**：本组 `border-radius:999px` 出现极高频（site_c 20 条圆角声明中多条 999px）。药丸按钮是 2021 年的 C 端糖果味，与"单据化 / 可审计"的严肃定位互相打架。

## ② 现有门面逐页批评

### `index.html`（聚合导航页，5.6KB）
**它是什么**：一个"HUB 页"，标题「一个平台，三个入口。」，6 张卡，其实混装了 3 个业务入口 + 3 个官网方向预览。

**踩雷**：
- **emoji 当图标（重）**：💰💬🔄🌊📜🥔 直接做 6 张卡的图标。其中 🌊📜🥔 还是拿 emoji 充当"设计方向"的视觉符号，等于用通用字形给"品牌方向"贴标签——最偷懒的一种。
- **渐变文字（重）**：H1 用 `linear-gradient(135deg, txt→cy→gold)` 三色渐变裁字，4 处 `background-clip:text`。标题本身信息是好的（"一个平台，三个入口"），但被糖纸毁了。
- **无意义持续动效**：`text-shadow:0 0 40px rgba(56,225,255,.15)` 泛光 + `fadeIn` 循环家族。
- **6 卡等宽网格**：`grid` + 6 张 `.card`，把"业务入口"和"设计预览"这两个**完全不同层级**的东西拉平成同一种卡——这是层级失败，不是设计。

**克制的地方**：
- 色板是干净的（深蓝黑底 + 青 + 金，**没有紫渐变**）。
- 无 backdrop-filter、无 canvas、无粒子。整体还算轻。

**致命伤**：这是**内部工具箱被误当门面**。三种官网方向（A/B/C）出现在"一个平台三个入口"里，会让外部读者完全困惑——读者只该看到一件事：我要去哪。

### `site_a.html`（方向 A · 深海军蓝 / 机构级）
**它是什么**：完整的单页官网骨架，6 个 section（services / ai / fees / flow / safety / faq）。视觉定位"机构级量化金融"。

**克制的地方（不少，值得肯定）**：
- **零渐变文字、零 emoji 图标、零粒子、零 canvas**。这是全组里对"反俗套"执行得最系统的深色页。
- 金色只用了 8 处引用，克制。青/金分工明确（青=数据/结构光，金=点缀），没有让金色去抢主视觉。
- 有真正的**结构化细节**：`radial-gradient` 网格底线（`rgba(255,255,255,.025)` 1px 网格）+ `linear-gradient(90deg, cyan, transparent)` 发丝线——这是"图纸感"，比发光高级。
- 文案是**事实型**的：费率 10/1.5/5% 明示、TF 单据、先单后扣、18+、区域合规。**没有一句"赋能/解锁/革命"**。这是这个项目最稀缺的资产。

**踩雷**：
- **英文 eyebrow 机械套用（7 处）**：`Global · Digital Asset Quant Infrastructure` / `Services` / `Platform AI` / `Transparent Fees` / `Pipeline` / `Safety & Audit` / `FAQ`。中文标题已经够清楚，英文小字纯属装饰性"高级感"，反而暴露模板痕迹。
- **阴影过重**：`0 30px 80px rgba(0,0,0,.45), inset 0 1px 0 rgba(255,255,255,.06)`——外投影 + 内高光的组合正是玻璃拟态的"招式"，虽然没用 backdrop-filter，但**视觉上已经玻璃化了**。
- **配图本身就是玻璃拟态**：hero 图和流程图都是 AI 生成的 base64 JPEG，alt 写着"五块深色玻璃方块沿青色光线依次连接"——**设计师在插画里又画了一遍玻璃拟态**。这是典型的"用 AI 生图补齐视觉、结果把俗套复制进画面"。
- **`.rv` 37 处 + `.d1~.d4` 阶梯延迟**：每个区块都淡入，节奏被拉平。
- **圆角过甜**：`20px / 18px / 14px / 999px` 混用，`999px` 药丸出现 4 次，与"机构级"的庄重感冲突。

**致命伤**：深色底的对比度管理偏弱——`--dim:#7E95A8` 压在 `#0B1E33` 上做正文级别的信息，长时间阅读会累。且 hero 是一张"数据地形"抽象图，**换成任何一家 AI 公司都成立**，没有品牌归属。

### `site_b.html`（方向 B · 冷纸编辑 / 账本）
**它是什么**：同一套文案的浅色版本。冷纸白 `#F5F4F0` + 墨蓝 `#16263B` + 深金 `#B78A2E` + Noto Serif SC 衬线。

**克制的地方（全组**最强**，应作为基准）**：
- **渐变数 = 0**。一个都没有。纯色平涂。
- **阴影只有 2 条，且都是柔影**（`.14` / `.15`），是唯一完全合格的一页。
- **圆角回到 2px**：`.doc` 系列元素用 2px 直角感，配 12 条 1px 发丝线——**这是"单据/账本"的正确形状语言**。金色只做 `--gold:#B78A2E` + `--gold-soft:.10`，18 处引用但都是细线级别。
- 编号索引 `.no`（01/02/03…）给了内容**扫描锚点**，替代了图标行堆砌。
- 衬线 + 无衬线的搭配有真正的编辑设计意识。

**踩雷**：
- **和 site_a 共享同一套模板骨架**：同样是 6 个 section、同样的 `.rv` / `.kick` / `.step` / `.sec-item` / `.fee`。**换皮不换骨**——这是当下"一次生成三个方向"的通病：三个方向其实是同一个模板换色。
- 英文 eyebrow 依然 7 处。
- `999px` 药丸混在 2px 文档条里，出现 1 次——小瑕疵，但破坏了整体的"账本"一致性。**要么全直角，要么全药丸，不能混。**

**致命伤**：浅色"账本"气质虽对，但**衬线没有真正承担标题**（字号阶梯还是 clamp 老配方），金色缺少一处"点睛"的高光时刻（比如一个金色印章式单据号），整体偏"灰"、偏"温"。方向对了，力度不够。

### `site_c.html`（方向 C · 品牌主角 / 赛博土豆）
**它是什么**：深色底 + 赛博土豆吉祥物站 C 位，视觉偏"IP 品牌页"。

**克制的地方**：
- 有真实品牌资产：吉祥物 3 张 AI 生成图（`赛博土豆站在发光的电路地板上` / `与悬浮的全息单据面板`），这是全组**唯一有专属记忆点**的页面。
- 9 个 `<svg>`，说明部分图形是矢量的，不是全部贴图。

**踩雷**：
- **霓虹点（真）**：`box-shadow: 0 0 12px rgba(53,224,255,.7)` —— 这是字面意义上的霓虹灯，色值透明度 .7，在深色底上会像 LED。用作"发光点"就是标准赛博俗套。
- **文字泛光**：`text-shadow: 0 0 24px rgba(53,224,255,.35)`，典型"深色底补光"。
- **阴影最重**：`0 34px 90px rgba(0,0,0,.5)` + `0 24px 60px rgba(0,0,0,.55)`，全组 Top。
- **金色退化**：CSS 变量里 `--gold` 缺失，金色只以 `#C98F4E`（`rgba(201,143,78)`）出现在 2 处环境光渐变里。**说明深色 + 鎏金的主基调在这一页被稀释成了"青色主导 + 一点暖光"**，金色只是氛围噪点，没有结构作用。
- **吉祥物与严肃定位冲突未被处理**：赛博土豆很萌，但页面同时在讲"密钥托管 / 幂等对账 / 审计留痕"。**萌 IP 与合规严肃性之间没有任何过渡设计**——不是不能共存，是不能不处理。
- 等宽 4 卡 `.card` + `ico` 图标行，仍是网格堆砌。

**致命伤**：方向 C 把"品牌"理解成了"放个吉祥物"，而真正的品牌是**一套可信的语气与形状**。目前是"严肃页面 + 贴了个吉祥物"。

### `exchange.html`（功能页 · 兑换）
**它是什么**：真实交互页（钱包连接、汇率、生成地址、开票、交易记录）。

**克制的地方**：
- 功能区划清晰：`兑换 / 收款地址 / 收款发票 / 交易记录` 四个 nav，信息架构没问题。
- 数据态有考虑空状态（`.empty`）与 toast。

**踩雷（全组最重的功能页）**：
- **backdrop-filter 5 处**（blur 12/8/6px）—— 明确滥用。
- **双辉光按钮**：`box-shadow:0 8px 40px rgba(56,225,255,.35), 0 0 80px rgba(56,225,255,.15)`。这是 2021 年 SaaS 落地页的**标准发光主按钮**，出现即俗。
- **渐变文字 4 处 + 9 个渐变**，含 `135deg, txt→cy→gold` 三色。
- **emoji 图标 14 种**：🦊🔗🛡📍🧾📊🏠💰🔄💬✕。**🦊 当钱包 logo** 尤其致命——钱包图标是金融界最需要"可信地辨识"的元素，用动物 emoji 会瞬间把产品拉进"小游戏"语境。
- **KPI 三连大数字**（已注册钱包 / 累计兑换 / 费用收入）——模板标配，且全是 `—`（演示占位），三根横杠并排，视觉空洞。
- `pulse` 无限循环动画 + 4 个 keyframes。
- `inline style= 23 处`——**样式系统失控**，说明这一页是"边写边打补丁"出来的。

**致命伤**：这是一页"能跑但不可信"的界面。功能对，质感错。金融兑换页的第一诉求是**让人敢把钱交出去**——发光按钮 + emoji 钱包 + 空心 KPI 三连，全是反向操作。

---

### `wallet_v2.html`（功能页 · 收款钱包）
**它是什么**：收款流程页（选支付方式 → 生成地址 → 链上确认 → 自动入账）。

**克制的地方**：
- **4 步流程用编号 + step-line 串联**（`1 选择方式 2 生成地址 3 链上确认 4 自动入账`），这是**正确的流程表达**——编号比图标行高级，且符合"可核验"的产品语气。这一点值得保留并推广。
- 把"收款不产生平台技术费 / 币→币 1.5%"直接写在流程里，事实型文案，好。

**踩雷**：
- **鎏金扫光文字（最俗）**：`linear-gradient(120deg, var(--gold) 10%, #fff 55%, var(--gold) 95%)` + `background-clip:text`。这是"婚礼请柬 / 信用卡广告"的招式，用在数字钱包上= 显廉价。
- **14 个渐变 / 13 条 shadow / 4 处 blur（6/8/14px）**——密度全组之最，典型的"元素不够、效果来凑"。
- **金色最重（31 处引用）却最没有结构意图**：`--gold-soft` / `--gold-line` 到处铺，金色变成了**氛围色**而不是**等级色**。金色一旦贬值，贵气就没了。
- 1 个 `<canvas>`（无 rAF，疑似装饰残留）。
- `pulse` 循环动画。

**致命伤**：金色用得最多，反而**最不贵气**。这是本报告的核心结论之一：**金的价值来自稀缺，不来自数量。**

---

### 跨页共性诊断（一句话）
> **三张官网是同一个模板换了三种颜色（换皮不换骨）；三张功能页把 CSS 噱头（发光/玻璃/渐变字）用到了不同深度。全组唯一的真资产是"事实型文案 + 单据化概念 + site_b 的账本形状语言"，唯一的真负债是"金色被当氛围色滥用 + emoji 图标 + 模板骨架"。**

## ③ 高级感艺术方向 · 深蓝 + 鎏金贵气（反俗套原则清单）

> 前提共识：**贵气 = 稀缺 + 精确 + 留白**。奢侈品的贵气从来不来自"金色很多"，而来自"金色很少，但每一克都用在刀刃上"。以下 14 条，逐条可执行、可验证。

### A. 色彩纪律（3 条）

**1. 金是"等级色"，不是"氛围色"——像素占比 ≤ 5%，且只出现在三类结构位。**
- 金色只允许出现在：① **1px 结构性分隔线 / 表头线**（如单据表头下的一条金线）；② **单据编号 / 关键数字**（TF 号、费率、金额）；③ **全页唯一的主 CTA**（最多 2 个）。
- 禁止：金色渐变描边、金色发光、金色文字填充大面积、金色做卡片背景。
- 验证：把页面转灰度，**如果金色区域消失后信息层级依然成立，说明金用对了**；如果消失后页面"塌了"，说明金在当氛围色干活，错。

**2. 深蓝底只允许"一层环境光"，禁止辉光叠加。**
- 页面最多 1 处 `radial-gradient` 环境光（暖金或冷青，二选一，不可同区叠加）。
- 同屏**发光元素 ≤ 1 个**，且只给当前唯一主行动点。判定式：截图里数有几个元素在发光，>1 即失败。
- 禁止 `text-shadow` 模糊 ≥ 20px 的泛光（`0 0 24px/40px` 一律删）。

**3. 色相预算：主色 1 个色系 + 中性 3 级 + 强调 1 个。**
- 深蓝做基底（明度分 3 档：底 / 面板 / 面板浮起），金色做唯一强调，青/绿仅用于**数据语义**（涨/跌、成功/失败），不得用于装饰。
- 验证：全站色卡里**装饰用色 ≤ 3 个**。超了就是"配色失控"。

### B. 形状与材质（3 条）

**4. 圆角全局统一为"结构家族"，禁止 999px 与 2px 共存。**
- 严肃金融门面建议：**卡片 4–8px，文档条 2px，药丸仅允许出现在"状态标签"一种组件上**。
- 禁止：同页并存 `24px / 20px / 999px` 三种圆角逻辑（当前 site_a / exchange 正是如此）。
- 验证：统计页面所有 `border-radius` 值，**独立取值 ≤ 3 个**。

**5. 用 1px 发丝线替代阴影做层级。**
- 深色底上，面板靠 **1px 半透明描边 + 极轻内高光** 立体积，而不是靠大外投影。
- 阴影上限：≤ 2 层，`blur ≤ 40px`，`alpha ≤ .30`。**模态/浮层**才允许例外。
- 验证：`grep box-shadow` 后逐个检查，凡 `blur≥60px` 或 `alpha≥.4` 的深色卡阴影，一律改写为描边方案。

**6. 玻璃拟态只留给"真的浮在上面"的东西。**
- 全站 `backdrop-filter` ≤ 2 处（建议：吸顶导航 + 模态遮罩）。
- 卡片一律实色面板。**能看见背后内容的模糊才叫玻璃，看不见的模糊只是糊**。

### C. 排版与文案（4 条）

**7. 标题靠"字重 + 字号 + 留白"立威，禁止渐变文字。**
- 全站 `background-clip: text` **≤ 1 处，且只用于超低强度同色系明度差**。
- **鎏金扫光文字（gold→white→gold）永久禁用。**
- 验证：截图放大标题，若能看出颜色在横向游走，即为失败。

**8. 建立 4 级字号阶梯并封顶。**
- 例：`H1 44–52px / H2 28–32px / 正文 15–16px / 标注 11–12px`，**共 4 级，不再多**。
- 行高：标题 1.15，正文 **1.7–1.85**（中文长文必须 >1.7），标注 1.4。
- 正文最大行长 **≤ 38 个汉字/行**（当前多处超长，读起来像条款公告）。

**9. 英文 eyebrow 要"有理由"，否则删掉。**
- 只有当真存在英文受众、且英文是**正式译名**时才出现；且**同一区块中文优先**。
- 禁止：把机翻短语（`Transparent Fees` / `Pipeline`）当装饰小字压在中文标题上。
- 验证：给一个不懂英文的读者看，如果他觉得"这行小字没影响理解"，说明它是装饰——删。

**10. 文案做"形容词审计"：凡不能被数字/流程/责任验证的修饰，删。**
- 保留并强化现有的**事实型表达**（"先单后扣""费率在订单与单据中明示""亏损不抽成""18+"）——这是本项目的护城河。
- 删除/禁用：赋能、解锁、革命、颠覆、极致、无缝、一站式的**装饰性用法**。
- 新增建议：把"失败怎么办"写进流程（"失败自动重试，不静默丢单"已有——把它做成**可见的 UI 状态**，而不只是文案）。

### D. 动效与图形（3 条）

**11. 动效只允许"入场一次"或"数据驱动"，禁止无限循环装饰。**
- 允许：入场淡入（≤ 600ms，播完即静）、数字滚动（真实数据）、进度推进（真实状态）。
- 禁止：`pulse` / `float` / `markFloat` 类**永不停歇**的装饰动画；首屏禁止循环粒子背景。
- 验证：静置页面 10 秒，**不应该有任何元素在持续变化**（除真实数据刷新）。

**12. 图标必须自建或严格统一：禁止 emoji 做图标。**
- emoji 只允许出现在正文口语。**导航/按钮/列表图标位一律禁用。**
- 箭头 `→` 可用，但仅用于流程串联（`收款 → 核验 → 处理 → 结算 → 单据对账` 这种），且统一字号/颜色。
- **🦊 类动物 emoji 当钱包 logo：永久禁用。**
- 验证：`grep` 页面，除 `→` 外不应出现任何 ✅❌💰 类彩色字形。

**13. 打破等宽网格：用"非对称 + 编号行 + 单据条"替代 2×3 SaaS 卡阵。**
- 主能力区：1 张大卡 + 2 张窄卡（非对称栅格）；次要信息：编号行 `01 / 02 / 03` 配 1px 分隔线。
- 同屏同类"图标+文字"行 **≤ 4 条**；超过改用两列文档条（`术语 —— 值`）。
- 禁止空心 KPI 三连（`— / — / —`）。要么有真数，要么整块删掉。
- 验证：把页面缩略图缩到 15%，**还能一眼看出"哪里最重要"**，才算过。

### E. 品牌与一致性（1 条，收口）

**14. 三个方向必须"换骨不换皮"：品牌骨架唯一，只有语气/材质可变。**
- 现状是三张官网共享同一模板骨架、只换色和材质——这是"一次生成三方向"的假多样性。
- 正确做法：先定**唯一的品牌骨架**（色板、字号阶梯、圆角家族、金的三处用法、单据编号样式），三个方向只允许在**深浅基调（深色机构 vs 浅色账本）**与**主视觉语气（抽象数据 vs 品牌 IP）**上分叉。
- 品牌 IP（赛博土豆）与合规严肃性必须**设计过渡**：例如把吉祥物处理成**极简线稿剪影 / 印章化单色金**，而不是"萌物贴在严肃页面上"。
- 验证：把三页的 logo 都遮住，**能否判断它们属于同一品牌**？不能，就是三个模板，不是一个品牌。

### 落地优先级（给主 Agent 的执行顺序建议）

1. **P0 · 立刻删**：emoji 图标（index / exchange / wallet_v2）、渐变文字（含鎏金扫光）、双辉光按钮、`pulse`/`float` 循环动画。
2. **P0 · 立刻改**：shadow 超标项（site_a/c、exchange/wallet）→ 换 1px 描边 + 内高光；`backdrop-filter` 收敛到 ≤ 2 处。
3. **P1 · 重构**：把 index 的 6 卡等宽网格拆成"3 个业务入口 + 1 个官网入口"的非对称结构，并把 A/B/C 方向预览从门面移除。
4. **P1 · 定标准**：确立唯一品牌骨架（色/字/角/金三用/单据号样式），再让 A/B/C 分叉。
5. **P2 · 提质**：金色收敛到"结构位"；统一中英文标点（当前正文混用 ASCII `,` 与中文 `，`、`:` 与 `：`）；正文行长压到 ≤ 38 字。
6. **P2 · 保留资产**：`site_b` 的账本形状语言 + `wallet_v2` 的编号流程 + 全组的**事实型文案**——这三样是反俗套的底子，别一起改掉。

---

> 结论一句话：**这个项目不缺"高科技感"，缺的是"克制"。把发光、玻璃、渐变字、emoji 四样俗套砍掉，剩下的深蓝底 + 青色结构线 + 事实型文案 + 单据化概念，本身就已经很贵了。金要留到最后才用，用得少才叫金。**
