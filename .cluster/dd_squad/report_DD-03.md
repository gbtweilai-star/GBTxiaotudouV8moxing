# DD-03 战报 · 下载/安装节

**通道自证**：本报告由主公（/root）执行；派单通道已实测不可用（见 `HEARTBEAT.md`）。
**方法论**：先看**真文件**、先调**真接口**，不从源码抄字面量（坑册 21）。

## 一、结论

**面板缺的不是"安装功能"，是"把已有的安装/启动入口呈现出来"。这是展示层缺口，不是功能缺口。**

⇒ **该有这一节**；但它**不该新造安装逻辑**，而应把盘上**已经存在**的入口如实列出来。
至于"点一下就能装"——那是给面板加**执行能力**，属权限边界变更，**要主人明确拍板**，我不擅自加。

## 二、证据（全部为读数）

### ① 盘上真实存在的启动/引导件（`Test-Path` 级证据，全部 `holo_pet/` 内）
```

⇒ 安装/启动这件事**已经在用另一种形式提供**，只是**不在面板里**。

### ② 桌面快捷方式——**真的都在**

⇒ 用户入口已经铺到桌面了。

### ③ 活面板 `/api/state` 的**真实键**（真调接口，非 grep）
```

⇒ **面板 API 里根本没有"安装/下载"这一域。** 面板管的是：内核通道、心智、生命档案、
蓝牙、感官、Notion、EigenFlux、星云数字人。

## 三、分析

```
主人的诉求             "我要在 APP 上面安装/下载，那里却空白"（两次）
盘上事实               入口有 5 个脚本 + 6 个快捷方式 —— 功能不缺
面板事实               API 无 install/download 域 —— 面板里没有这一栏
⇒ 缺的是**呈现**，不是**能力**
```

顺带修正一处我早先的说法：我曾写"面板 grep「下载/install/安装」**零命中**"。
那是对 `app.js`/`index.html` 的 grep（**源码字面量**）；按坑册 21，它只能说明
"源码里没有这几个字"，**不能**直接推"面板里没有这一节"。真正的读数在上面第 ③ 条：
**API 里没有这一域** —— 这才站得住。

## 四、缺口与风险

| # | 项 | 性质 | 处置 |
|---|---|---|---|
| 1 | 面板无"启动与安装"呈现区 | 展示层缺口 | 建议补：**只读列表**，逐条列出上面 6 个真实入口 |
| 2 | "点一下就能装/启动" | **权限边界变更**（面板获得执行能力） | **要主人拍板**；我不擅自加 |
| 3 | 快捷方式是否指向有效目标 | 未测 | 可另开一枪：逐个解析 `.lnk` 目标并 `Test-Path` |

## 五、建议落点

1. **先做只读版**（低风险、马上有用）：在面板加一节「启动与安装」，
   内容 = 上面 ① 的 6 条（名字 + 大小 + 一句用途），**每条都由 `Test-Path` 现场校验**，
   不存在的就如实标"缺失"。这符合面板"本地只读看板"的既有定位。
2. **执行版暂缓**：给面板加"点一下就跑 .bat"= 让它获得执行能力，
   要和 `auth_gate` 的口径对齐（谁是发起者、要不要主人确认、留什么审计），**这属于设计决策**。
3. **第 3 项另开一枪**：解析桌面 `.lnk` 的真实目标并逐个验在不在 —— 你之前吃过
   "快捷方式看着有、点开不对"的亏。
