### 1.1 两把门，两把钥（**这是最容易混的地方**）

```
   DSH / Codex / 任何前端
          │
          ▼
   ┌─────────────────┐      要 GW_AUTH          ┌──────────────────┐      要 rpa_      ┌─────────────┐
   │ Worker（云上拼接网）│ ──────────────────────▶ │ RunPod Serverless │ ───────────────▶ │ 我们的权重    │
   │ gbt-potato-cloud-10│                        │ gbt-v8-live       │                  │ gbt-v8-weights│
   └─────────────────┘                          └──────────────────┘                  └─────────────┘
        ↑ 门①：网关鉴权                                ↑ 门②：RunPod 鉴权
```
