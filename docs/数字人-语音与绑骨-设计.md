## §2 骨架结构图（关节名与层级）

**方位约定**：`L/R` = **她自己的**左/右。她是正面朝观众的 ⇒ **她的右手在画面左**。
**骨骼约定**：每根骨在**本关节局部坐标**里从 `(0,0)` 画到 `(0,len)`，宽 `w`；
`off=[dx,dy]` 是**相对父关节**的平移（在父的局部坐标系里）；`rest` 是静息角（度）。
SVG 的 `rotate` 正角 ⇒ 骨尖朝 **-x**（屏幕左）。
**镜像律**：`rest_L == -rest_R`，且任何**对称动作**的增量也必须 `delta_L == -delta_R`（机检件拿这条去红）。

```
pelvis 髋（根 · rest 0 · 骨长 30）
├─ spine 脊（off [0,-32] · 长 30 · 腹）
│  └─ chest 胸（off [0,-30] · 长 30 · 躯干/肩带）
│     ├─ neck 颈（off [0,-52] · 长 14）
│     │  └─ head 头（off [0,-14] · 长 -56【负=骨尖朝上，骨叠加看起来才像人】）
│     │     └─ jaw 下颌（off [0,24] · 长 18）—— 嘴型的"张"由它 + 嘴型 path 一起给
│     ├─ clavicleL 肩/锁骨（off [12,-40] · 长 26 · rest -90 · 骨尖朝 +x）
│     │  └─ upperArmL 上臂（off [0,26] · 长 56 · rest 83）—— 与锁骨反向，合起来才是"手臂垂下"
│     │     └─ foreArmL 前臂（off [0,56] · 长 52 · rest 3）
│     │        └─ handL 手（off [0,52] · 长 22 · rest 2）
│     └─ clavicleR 肩/锁骨（off [-12,-40] · 长 26 · rest +90）
│        └─ upperArmR 上臂（off [0,26] · 长 56 · rest -83）
│           └─ foreArmR 前臂（off [0,56] · 长 52 · rest -3）
│              └─ handR 手（off [0,52] · 长 22 · rest -2）
├─ hipL 髋(腿根)（off [14,0] · 长 0 · rest -2）
│  └─ thighL 大腿（off [0,0] · 长 130 · rest 0）
│     └─ shinL 小腿（off [0,130] · 长 130 · rest 0）
│        └─ footL 脚(踝)（off [0,130] · 长 34 · rest -10）
│           └─ toeL 脚掌（off [0,34] · 长 16 · rest -16）
└─ hipR 髋(腿根)（off [-14,0] · 长 0 · rest 2）
   └─ thighR 大腿（off [0,0] · 长 130 · rest 0）
      └─ shinR 小腿（off [0,130] · 长 130 · rest 0）
         └─ footR 脚(踝)（off [0,130] · 长 34 · rest 10）
            └─ toeR 脚掌（off [0,34] · 长 16 · rest 16）
```

- **关节总数 24**（含下颌）· **镜像对 9 对**（clavicle / upperArm / foreArm / hand / hip / thigh / shin / foot / toe）。
- 主人点名的结构全在：髋 `pelvis` · 脊 `spine` · 胸 `chest` · 颈 `neck` · 头 `head`；
  双臂 肩 `clavicleL/R` - 上臂 `upperArmL/R` - 前臂 `foreArmL/R` - 手 `handL/R`；
  双腿 髋 `hipL/R` - 大腿 `thighL/R` - 小腿 `shinL/R` - 脚 `footL/R`；**脚掌** `toeL/R`。
- **正向运动学（唯一真相）**：`关节世界位姿 = 父世界位姿 · translate(off) · rotate(rest+Δ)`，
  再把**渲染时同样施加的两个根变换**算进来 —— ① 根平移 `rootX/rootY`；② `yaw` 的水平前缩 `sx=cos(yaw)`（夹到 ±0.28）。
  🔴 初版漏了这两条 ⇒ 蹲下被量成"髋没动"、转身被量成"没动"。这是本页自己踩并修掉的坑（见 §5）。
- **静息对称**：现量 **最大镜像误差 0.0000px**（9 对全过，容差 0.5px）。镜像是**算出来的**（同一套 fk 走两遍），不是画的时候手动对齐。

## §3 动作清单（驱动方式 + "怎么证明真在动"）

驱动方式统一是：**关键帧（角度增量/根量）→ 段内 smoothstep 插值 → 写进关节的 `translate(off) rotate(rest+Δ)`**。
**"真在动"的判据四条**（页面与机检件各实现一遍，读数必须一致）：

| # | 量 | 门限 |
|---|---|---|
| ① | **幅度** `d2` = 相对 t=0 的最大角偏移 | > 5° |
| ② | **连续性** `d1` = 相邻帧最大 \|Δ角\| | > 0.2°（防"跳变换图"） |
| ③ | **位移** = 关节世界坐标相对 t=0 的最大位移 | > 2px |
| ④ | **对基线** | 幅度与位移**都**要 > **2 × 现量基线**（基线 = 同一套 41 点采样跑 idle 得到，**不是常数**） |

> 另外有一个**伪关节 `root`**（角度 = `yaw`、位置 = 根位移）必须计入 —— 转身/走动/蹲起的驱动量在它身上，
> 不算它，转身会被误判成"没动"（它每帧只转几度，但总量 360°）。

| 动作 | 中文 | 驱动方式（关键帧内容） | 真在动的判据（机检 + 页面两套独立实现，读数一致） |
|---|---|---|---|
| `idle` | 常态呼吸 + 微重心漂移 | `breath` 0→0.55→0.15→0.4 循环；`head/neck/chest` ±1.2°；两臂 ±1.4°（镜像）；`rootY` ±1.6、`rootX` ±1.2 | **它是基线本身**：幅度 **2.60°** / 单帧 **0.53°** / 位移 **3.38px** ⇒ 判据反过来"必须很小"，量级正确才可当底数 |
| `talk` | 说话：嘴型 + 点头 + 手势 | `mouth` 0→0.85→0.10→0.70→0.05→0.90→…（10 帧）；`neck` ±3.4°；`upperArm ±14°`、`foreArm ±40°`、`hand ±34°`（全部镜像对称） | **真在动**：幅度 **67.00°**(handL) · 单帧 **20.11°** · 位移 **24.45px**（>2× 基线） |
| `wave` | 抬手打招呼 | `clavicleR` -18 → `upperArmR` -152（抬到头顶外侧）→ `foreArmR` -6 / -38 交替 **摆三下** → 落下 | **真在动**：幅度 **229.75°**(handR) · 单帧 **38.74°** · 位移 **207.59px** |
| `walk` | 走动两步（3/4 视角） | `yaw` 恒定 30°；`thighR/thighL` 交替 ∓18/±10；`shinR/shinL` 膝屈 -30/+14；两臂反相 ±18°；`rootX` 0→24（真的走两步）、`rootY` 0→-6 起伏 | **真在动**：幅度 **74.00°**(footL) · 单帧 **21.05°** · 位移 **196.91px**(toeL) |
| `turn` | 转身一整圈（**2.5D**） | `yaw` 0→34→122→**180**→238→326→**360**；两臂 ±10° 镜像摆动 | **真在动**：幅度 **360°**(root) · 单帧 **16.40°** · 位移 **58.85px**(handR)。**如实标注是 2.5D**：yaw 经"水平前缩 scaleX 1→-1 + 深度换序"表达，不是真 3D 旋转 |
| `crouch` | 蹲下再起 | `rootY` 0→18→**70**→70→12→0；`thighL +43 / thighR -43`；`shinL -86 / shinR +86`；`footL +53`（保持脚掌贴地）；`chest` 前倾 14° | **真在动**：幅度 **56.00°**(foreArmR) · 单帧 **8.25°** · 位移 **97.61px**(shinR)。髋世界 y 实测 **300 → 370**（真降 70px），膝 y **429.9 → 468.1** |
| `stretch` | 伸懒腰 | 两臂上举 `upperArmL -158 / upperArmR +158`（镜像）；`clavicle` 抬 ±17°；`chest -7°`、`spine -5°`、`head -13°`；`mouth` 0.9（打哈欠） | **真在动**：幅度 **191.00°**(foreArmL) · 单帧 **22.90°** · 位移 **232.01px**(handL) |
| `refpose` | 照参考图的姿势（一手抬到头发） | **单帧静态**：`upperArmR -46`、`foreArmR -98`、`handR -26`、`clavicleR -22`、`yaw 8`、`rootX 4` | **静态姿势**（`dur=0`、一个关键帧）⇒ **不进"真在动"判决**（硬凑成"在动"才是假绿）。它的用途是第 ③ 卡的 1:1 对照与"模仿参考图"的定妆镜 |

**怎么判定"真在动"（而不是"坐标合法"）**：上面四条**同时**成立才算，且第 ④ 条要求超过**现量基线**。
页面把每一项都**逐关节贴出来**（`t0 角 / 幅度Δ / 单帧Δ / 位移px / 真在动`），
**并另出"连续帧图条"**：同一个 rig 在 `t=0/.2/.4/.6/.8/1.0` 六个采样点上**重画**（不是预渲染贴图），
每格标出该帧相对 t=0 的 `maxΔ`（>3° 的格子标题变金色）。取证图与读数**同源同帧**。

**判据自己也被测过（负对照 4 条，全部按预期报红）**：

### 4.3 自动播放策略（与嗓表是**两件独立的事**，别混）

- 页面**不写任何绕过自动播放的 hack**（不假装点击、不监听别的窗）；只**如实使用** `speak()`。
- 首次 `speak()` 若 **既没 `onstart` 也没 `onerror`**（2.2s 超时）⇒ 页面判「**被自动播放策略拦**」
  并标成「待一次点击后即可发声」，**同时**在主人第一次点击任意按钮后**自动恢复**（`unlockGesture()`，后续不必再点）。
- 与之并列的另一种失败是 **`onerror: not-allowed`**（也是被策略拦）与**嗓不存在**——三者页面分开显示，不合并。
- **这页注册进壳时"需要什么"**：`"audio_autoplay": true`（⇒ 壳把 `autoplayPolicy` 设为
  `no-user-gesture-required`，数字人才能"有话就说"）。**登记由主人做，我没改 `shell/windows.json`**。
  不写 / `false` 时页面照常工作，只是第一次出声前需要一次点击。

### 4.4 面板桥为什么走壳口（而不是让页面自己出网）

- 页面**离线自包含**是硬保证：CSP `connect-src 'none'` ⇒ 任何网络取数原语都被浏览器**当场拒绝**。
- 主人令重申「不要动 CSP、不要放开页面的网络面」⇒ **已采纳"壳侧加 IPC 口"这一路**：
  壳里 `ipcMain.handle("w3:message", …)` → `w3Message()`，**目标写死在壳里**（`127.0.0.1:8765/api/message`，
  页面给什么都改不了它 ⇒ 连别的地址都构造不出来，防 SSRF）；preload 暴露 `window.gbtW3.message({text})`；
  返回形状 `{ok, status, reply}` / `{ok:false, error:"…原文…"}`。
- **页面侧对应**：拿得到 `reply` ⇒ 第 ⑤ 环标「通」并把回包**容错解析**（是 JSON 就挑 `reply/text/answer/message/content/output/result/data` 这些可读字段；
  解析失败就**原样显示文本**，绝不因解析失败显示空白）；`ok:false` ⇒ 把 `error` **原文照打**。
  壳外（浏览器直开）必然拿不到这个口 ⇒ 页面如实标「**壳外无此口**」并保留纯本地行为，**不伪造成功**。
