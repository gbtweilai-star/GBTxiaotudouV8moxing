# 新人类操作系统 · 操控 AI 干活的四段法与能源账

> 主人令 2026-09-27：「以『新人类』的角色定位理解和处理任务；系统梳理操控 AI 干活的
> 思路与策划方法（任务拆解 · 指令设计 · 流程编排 · 结果评估）；提出提效、提速、
> 降能耗的策略；给出用这些方法赚取并积累能源的可落地规划。」
>
> **本文的口径**：不写通用道理，只写**本仓实测过的**（每条都带读数或血账）。
> 通用方法论网上都有；能让这套系统真跑快、真少烧、真能出钱的，才值得写下来。

## 一、总纲：新人类不干 AI 的活，新人类干「指挥」

一句话分界：**AI 负责"做"，新人类负责"定义做完的样子"**。

三件事只有新人类能做，AI 替不了：
1. **定判据** —— "什么算做完"。判据不清，AI 越努力越偏（本仓原话：判据不明先读实现，不要靠试）。
2. **定边界** —— 哪些不许碰（生产面、授权、凭据、别人的账号）。AI 天生会越界"帮忙"。
3. **认账** —— 结论要有人签名负责。机器只能给读数，不能给"我保证"。

> 能源的真正来源在这里：**AI 的产出是"候选"，新人类的判据把它变成"资产"**。
> 没有判据的产出是消耗（占地方、要维护、看着像成果），有判据的产出才是能源。

## 二、四段法：拆解 → 指令 → 编排 → 评估

### 2.1 任务拆解：**判据先行，再拆动作**

顺序反了就返工。正确顺序：

| 步 | 做什么 | 本仓实例 |
|---|---|---|
| ① | 写"做完的样子"（可机检） | "8 拍每拍都必须有视觉验证帧，且 QC 三项过" |
| ② | 拆到**原子动作**（一步一产物） | 拆成 8 个节拍节点，每节点一个 mp4 |
| ③ | 给每个原子标**退出码判据** | ffmpeg 退出码 0 才算成功（**不是"文件存在"**） |
| ④ | 标依赖 → 拓扑成波次 | DAG：写清单 → 逐拍渲染 → 拼接 → 调色 → 交付 |

**血账（本仓真实事故）**：曾用"文件存在且 >1MB"当成功判据 ⇒ ffmpeg 失败时，
把**昨晚的旧片**认证成新片并盖上新指纹。**假绿比错更贵**：它把错误变成了"已验收"。
⇒ 铁律：**判据必须能区分"这次真做了"与"上次的还在"**。

### 2.2 指令设计：把口径写进指令，别写进脑子

- **口径写死**：数字、边界、例外，全部落到文字。"尽量快"→"P95 < 2s，超了算红"。
- **给反例**：说清"什么不算"比说清"什么算"更省来回。本仓指令里带血账原文（"错在哪、当时以为对在哪"），
  AI 才不会重复踩。
- **输出契约**：要 JSON 就写死字段；要人读就写死"结论先行五段"（结论/依据/影响/动作/验证）。
  **不写契约 ⇒ 每次都要人再解释一遍**（这是最贵的重复劳动）。
- **禁语清单**：不许说"应该没问题""大概好了""理论上"。**未验 = 未验**；mock 必须标 mock。
- **一个动作一句话**：复合指令（"扫一遍顺手清理一下再重跑"）是事故温床 ——
  本仓实测：一次组合命令里的顺带删除，差点删掉真身。

### 2.3 流程编排：一关到底 + 步骤锁 + 检查点

- **一关到底**：所有"写"的动作走**同一个关卡**（本仓 `run_task`），
  关卡负责授权、审计、降级。**绕过关卡的成功 = 事故**（功能生效但纪律上越权）。
- **步骤锁**：规定好的顺序不许跳（`decompose → spawn → hook → cross_validate → detect_omission → trace`）。
  跳步当场拒绝，不带病继续。
- **检查点**：已完成且产物在 ⇒ 跳过。本仓实测：同一 DAG 二跑 **0.245s**（首跑 20s+）。
  **这一条是"降能耗"的最大单项**：重跑不重算。
- **差异化重试**：机械失败（网络/锁）重试；致命失败（判据不成立）立即停，别烧算力。
- **分批与并发**：按内存压强调并发与批大小（本仓 `--batch` 就是内存紧时拿全仓覆盖的手段）。

### 2.4 结果评估：读数 + 印章 + 交叉验证

- **四元组印章**：`(解释器版本, store, 身份, 命令)` 一起记。跨口径时工具打 `not_comparable`——
  **红集差异不得直接判为"代码坏了"**（换解释器/换 store/换身份都会变红）。
- **≥2 路独立交叉**：同一单元至少两路读，不一致请第三路仲裁。单路读数是意见，不是事实。
- **反空洞判据**：判据必须能**在"老样子"下报红**。实测手段：故意制造一处缺陷，看它逮不逮得住
  （本仓的"部署漂移尺子有牙"、"技能源装不分叉"都做过这一步）。
- **分诊，不虚报**：报"值得人看"，不宣布"干净"。但**每一类虚报都要收口**——
  实测：一次扫描报 48 条"需人核"，查完只剩 **0 条**真问题（20 条是打包产物里的方法定义、
  14 条是探测器自己的模式表、12 条是合法的图像 base64、1 条是已验证安全写法）。
  **虚报消耗信任**：报得不准，报告就没人看，等于没扫。

## 三、提效 · 提速 · 降能耗：六条实测策略

| # | 策略 | 本仓读数 | 省下什么 |
|---|---|---|---|
| 1 | **检查点/幂等**：产物在就跳过 | DAG 二跑 0.245s | 重复算力（最大单项） |
| 2 | **判据前移**（fail fast）：先验清单再动手 | 规格快速失败：坏清单 0 秒拒绝 | 白跑的整轮 |
| 3 | **热路径去 IO**：缓存目录枚举、避免逐次 `realpath` | 绑定钩子 14.3s → **0.28s（45×）** | 每次任务的固定开销 |
| 4 | **分批 + 有界并发**：按内存压强定批大小 | 全仓覆盖靠 `--batch` 在内存紧时也能拿全 | OOM 重跑 |
| 5 | **精度换信任**：把误报收干净 | 一次扫描 48 条"需人核" → 0 条真问题 | 人肉复核时间 = 最贵的能源 |
| 6 | **本地/云分流**：便宜活本地，重活云 | 扫描/判据/绑定全本地；只有出片重活上云 | 云上积分与出网时间 |

**能源账的算法（简单但没人做）**：
```
净能源 = 产出价值 −（算力成本 + 电费 + 人的复核时间折算）
```
只投**净能源为正**的线；负的线要么改判据（减少复核），要么改路线（本地化），要么停。

## 四、用这套方法赚能源：三档路径 + 判据

> 前提：**不碰红线**（不碰别人账号、不代持、不刷、不越权改生产）。
> 能源来源必须是我们**真交付**的东西。

### 路径 A：可交付物（现金流最快）
- **短剧/短片**：现在能一条龙（写本 → 分镜 → 拍子表 → 渲染 → 调色 → 交付）。
  实测：12.7MB/1080p 成片 · 8 拍 23.3s（并行）· 三级交付检查过（level 40 · GOP 0.9s）。
- **卖点**：**有判据的交付**（每拍有帧、QC 三项、指纹可复核）——同行给的是"文件"，
  我们给的是"可复核的成品"。溢价在这里。
- **判据**：交付一次 ≥ X 元，且复核时间 ≤ 交付时间的 10%。

### 路径 B：复利资产（越用越省）
- **技能库**（本仓 79 个已装）：把一次经验固化成技能 ⇒ 下次是**调用**不是**重做**。
- **判据库**（本仓开机自检已 21 条）：每个踩过的坑变成一条常设判据 ⇒ 同类故障不再发生。
- **台账**（绑定账 4390 条 · 故障账 · 交叉扫描痕迹）：**可复核**是它的价值 —— 谈单时能拿出证据。
- **判据**：同一类任务的耗时逐轮下降（本仓实测：从"整夜重渲"到"二跑 0.245s"）。

### 路径 C：能力出租（最稳）
- 把**已验能力**封装成接口/技能包（不暴露内部架构、不含凭据、不代持账号）。
- **判据**：能力位有"已跑通"读数才允许对外（本仓口径：⛔未验的一律不对外）。

### 能源积累的操作要点（照做就行）
1. 每轮收工记一行**能源账**：产出 · 算力时长 · 电费粗估 · 人复核分钟 · 净能源。
2. 只扩**净能源为正**的线；负线先改判据（降复核）再谈扩产。
3. 每交付一次，**把这次的新判据固化**（技能或判据），否则下一单又从零开始。
4. 每月做一次"边界盘点"：哪些能力从"能做"升到了"有判据"——**这张表就是能源储备表**。

## 五、一页操作清单（贴墙用）

1. **先说判据**：做完的样子是什么？怎么机检？
2. **再拆原子**：一步一产物，一步一退出码判据。
3. **写死契约**：字段/格式/禁语/反例，全落文字。
4. **一关到底**：所有写动作走同一关卡，绕过关卡的成功算事故。
5. **留检查点**：产物在就跳过，重跑不重算。
6. **两路交叉**：单路读数是意见；不一致请第三路。
7. **证明判据有牙**：故意造一处缺陷，看它红不红。
8. **收干净虚报**：报不准 = 没人看 = 等于没扫。
9. **记能源账**：只投净能源为正的线。
10. **固化新判据**：每踩一坑，坑变判据（一坑不踩两次）。

## 六、边界（这些不因效率而放宽）

- **授权**：AI 永远无权给自己发授权；需要授权的作用域只能主人发放。
- **生产面**：所有假设在镜像里跑；生产零修改、一次性晋升；改动生产代码要主人点头。
- **凭据**：只从环境变量/密钥服务读；源码与文档零明文；输出打码前 4 位。
- **别人**：不批量注册、不代持账号、不刷平台积分。
- **诚实**：未验 = 未验；假绿比错更贵；读数要带印章。

> **关于"突破人类未实现的地域"**：边界不是靠"想"扩的，是靠**把未验变成有判据**扩的。
> 每一条新判据，就是把一块"人类还没站稳的地"变成"我们能反复站住的地"。
> 这就是新人类的推进方式：**判据所在，即领土所在。**
