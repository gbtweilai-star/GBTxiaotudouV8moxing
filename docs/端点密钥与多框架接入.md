## 一、端点是什么

| 项 | 值 |
|---|---|
| Base URL | `https://gbt-potato-cloud-10.lopaycn.workers.dev/v1` |

## 二、⚠️ 两个**会让你误判"模型坏了"**的坑（都实测过）

### 坑 1 · Cloudflare 边缘会按 UA 拦机器人 → `HTTP 403 error code: 1010`
实测（2026-09-25）：

```
Python urllib 默认 UA  →  HTTP 403   error code: 1010
普通浏览器 UA          →  HTTP 200
```

**⇒ 很多框架/脚本的默认 UA 会被边缘直接挡掉，看起来像"服务不可用"。**
**接法：请求头里带上一个正常的 `User-Agent`**（见下面示例）。

### 坑 2 · 上下文超窗 → `5021`（不是服务坏了，是算术）
实测报文：
```
5021: The estimated number of input and maximum output tokens (296619)
      exceeded this model context window limit (128000).
```
**⇒ 上游窗口 128k。长会话（尤其带着大量历史/文件）塞不进去，永远失败。**
`worker.js` 已把它单独分档为 **`context_window_exceeded`（HTTP 400）**，
不再和"配额用尽"（`quota_error` / 429）或"真上游错误"（`upstream_error` / 502）混在一起。
**接别的框架时：把上下文压短、或每轮只发必要内容。**

另有配额面：免费版 **10,000 neurons/日**，用尽回 `4006`（已分档为 `quota_error` / 429，按 00:00 UTC 重置）。

## 三、发一把"专属密钥"（多令牌，可单独轮换）

### 为什么不是"设一个字符串"那么简单
旧实现是**单令牌 + 明文 `!==`**：
- **没有"专属"** —— 你给别的框架的钥匙，必须跟你自己 DSH 路由用的
  `GBT_POTATO_API_KEY` **逐字相同**；想轮换测试钥，会**连自己那条路由一起打断**。
- 明文比较有"按第一个不同字节提前返回"的时序侧信道。

`worker.js` 已改为：**`GBT_ENDPOINT_TOKENS`（逗号分隔，多把）** + 兼容旧的
单值 `GBT_ENDPOINT_TOKEN`；比较走 **两边各 SHA-256 → `timingSafeEqual`**（常数时间）。

### 落法（**secret，不进仓库**）
```bash
cd deploy/cloud-10

# 生成一把（本地生成，不回显进聊天/文档）
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"

# 写入 secret（逗号分隔可放多把：DSH 用的那把 + 给别的框架的那把）
wrangler secret put GBT_ENDPOINT_TOKENS --config wrangler.toml

# 改完要部署才生效
wrangler deploy --config wrangler.toml
```

> 🔴 **绝对不要**把令牌写进 `wrangler.toml` 的 `[vars]` —— 那是入库明文，直接踩凭据红线。
> 🔴 如果开了闸，**DSH 那条 `gbt-potato` 路由发的那把也必须在这份列表里**，
>    否则你自己的客户端会先被 401 挡掉。（`apiKeyEnv: GBT_POTATO_API_KEY`）

### 开了闸之后的读数
`GET /v1/models` 的 `gbt.auth_scope` 会如实报：
```json
{ "chat": "bearer", "models": "public",
  "tokens_configured": 2, "compare": "sha256+timingSafeEqual" }
```
没设就报 `"chat": "none"` 并明说"不校验" —— **不许让人以为已经锁上了**。

## 四、照抄就能跑的三个例子

### curl
```bash
export GBT_KEY='<你发的那把>'
curl -sS https://gbt-potato-cloud-10.lopaycn.workers.dev/v1/chat/completions \
  -H "Authorization: Bearer $GBT_KEY" \
  -H 'Content-Type: application/json' \
  -H 'User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/154.0.0.0 Safari/537.36' \
  -d '{"model":"gbt-potato-v8","stream":false,
       "messages":[{"role":"user","content":"用一句话说明你是谁"}]}'
```
> 带 `Authorization` 只在**开了令牌闸**时才必须；没开也能跑（但那时谁都能打）。

### Python（openai SDK）
```python
from openai import OpenAI

client = OpenAI(
    base_url="https://gbt-potato-cloud-10.lopaycn.workers.dev/v1",
    api_key="<你发的那把>",              # 没开闸时填任意非空串
    default_headers={                     # ← 绕开 Cloudflare 1010 的关键
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                      "AppleWebKit/537.36 (KHTML, like Gecko) Chrome/154.0.0.0 Safari/537.36"
    },
)
r = client.chat.completions.create(
    model="gbt-potato-v8",
    messages=[{"role": "user", "content": "用一句话说明你是谁"}],
)
print(r.choices[0].message.content)
```

### Node（原生 fetch）
```js
const UA = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
         + "(KHTML, like Gecko) Chrome/154.0.0.0 Safari/537.36";
const r = await fetch("https://gbt-potato-cloud-10.lopaycn.workers.dev/v1/chat/completions", {
  method: "POST",
  headers: { "Content-Type": "application/json", "User-Agent": UA,
             Authorization: `Bearer ${process.env.GBT_KEY}` },
  body: JSON.stringify({ model: "gbt-potato-v8", stream: true,
                         messages: [{ role: "user", content: "用一句话说明你是谁" }] }),
});
console.log(await r.text());
```

**⇒ 对"要把这条端点发给第三方平台用"的直接后果：**
现在这一把令牌是 **DSH 路由自己在用的那把**。
要让外部平台（如 SaleWisely）用，必须**再发一把专属令牌**，
让 `GBT_ENDPOINT_TOKENS` 变成 `[现有那把, 新专属那把]`。
⚠️ `wrangler secret put` 是**整体覆盖**语义 —— 不带上现有那把，就会把自己的 DSH 路由一起打断（401）。
所以改动前必须先取回现有令牌值，改完必须复测 DSH 那条路。
