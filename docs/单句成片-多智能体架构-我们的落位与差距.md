## 一、结论先行

它的核心判断（「瓶颈不是模型能力，是**编排的确定性**」）**我们认**，而且我们的架子**天然长在它的方向上**：
万能插 `run_task` = 唯一门 · 能力注册表 = 原子能力层 · 拍子表/清单 = Spec · 台账 = 资产与状态层。

**但它点的四个"下沉"，我们只落了两个半**：步骤与知识已下沉（清单 + 追加式台账），
**参数下沉（强 Schema）与"确定性可复现"这一半本轮才补**。

**本轮补了它十条关键点里我们真缺的四样**（全部实测，见 §三）：
① 规格强校验 fail-fast（关键点 1 的同类病）② seed 族策略（关键点 4）③ 成片指纹可复现（关键点 7）④ 预算闸降级（关键点 8）。
**剩三个大件**列入路线（§五）：DAG 并行编排 · 任务状态机/断点续跑 · 一致性锚点资产库。

## 二、七层对账（逐层点名，我们的落点在哪里）

| 它的层 | 我们的落点 | 状态 |
|---|---|---|
| ① 输入面 | 拍子表/清单（manifest）+ `omni.py ask`（人话落位）+ `look_grade.pick()`（人话取味） | ✅ |
| ② 意图编译层 | `omni.py`（人话→能力位）+ `gs_h3`（H3 提示词工程，5 模式规则）+ `specguard`（**本轮新增**：Spec 强校验 + seed 族补全） | ✅（Spec 用「清单 + 守卫」，不是自然语言） |
| ③ 群控编排层 | `media_run`（链执行器）· `filmkit`/`actioncam`（拍子表线性编排）· n8n 桥（外部触发）· `penetrating_cross_scan`（覆盖审计） | 🟡 **线性编排有，DAG 没有**（它要的并行+依赖还没做） |
| ④ 原子能力层 | **185 能力位** + 契约测试 + `caps_registry`；接线三处（注册表/分派/门） | ✅ 比它更进一步：我们**有门的唯一性**（它是"契约"，我们是"契约+授权门"） |
| ⑤ 质量审计层 | **三板块总监令**（验收标准）+ `qc`（黑帧/卡帧/亮度机械化）+ 交付前亲眼看 + 留样三帧制度 | ✅（VLM 多维打分那一格我们没有，见 §四·5） |
| ⑥ 资产与状态层 | **追加式台账**：`asset_bindings.jsonl`（绑定）· `cross_scan_trace.jsonl`（穿透扫描）· `film_qc.jsonl`（质量）· `*.fingerprint.json`（**本轮新增**成片指纹） | ✅ 知识下沉已落 |
| ⑦ 成片合成 | `filmkit`/`actioncam` build（音效床 + 外观库调色 + loudnorm）+ 外观库 `filmgrade` | ✅ |

**三处"我们和它不同、且我们不打算照抄"**：

1. **ComfyUI 依赖**：它的原子能力层是 ComfyUI Adapter（语义锚点→node ID 映射）。我们**本机没有 ComfyUI**（无独显/盘不够），
   出图走 pollinations/genoffice（`actioncam.source` 一个词换源）⇒ **它的"节点寻址版本化"在我们这儿对应的是
   "清单字段契约化"**（`specguard`），病同源、药不同。
2. **显存门禁**：它轮询 `/system_stats` 控显存水位；我们的对应物是**内存压强派单制**（本机<1GB 即派云）+ 负载闸 `--batch`。
3. **确认点**：它的闸门是"低置信度回问"；我们的门有两道——**安全门**（`auth_gate`，缺授权如实报缺）
   + **验收门**（总监令/QC/亲眼看）。**"置信度闸门"这一格我们确实没有**（见 §四·6）。

## 三、本轮补的四样（全实测）

| 补件 | 对应关键点 | 实测读数 |
|---|---|---|
| **`tools/specguard.py` 规格守卫** | 1（同类：不合法不许静默跑） | 负控清单 7 处错误**全部点名**（非法画质/缺 output/dur=0/短 prompt/未知运镜/缺 prompt/id 重复）⇒ **退出码 2 拒跑**；正控真清单照常过 |
| **seed 族策略** | 4 | `seed_family(base, n, stride=7919)`：同族锚固定 + 跨拍派生；`apply_seed_family()` **只补缺的**（定过的种子是资产不动）；清单落 `seed_base` |
| **成片指纹** | 7 | `actioncam-demo-拍子表-1080p.mp4.fingerprint.json`：清单 `fb21df2dd4a3a4ad` · 成片 `552124b33ec398fa` · 工具链 3 个 hash · 引擎 `python 3.12.10 / ffmpeg 8.1.2` |
| **预算闸** | 8 | `budget_gate()`：`budget={minutes,retries,on_exceed}`，超限**降级**（cinema→fhd→hd / 减拍）或停，**不许无限重试** |

**fail-fast 已挂进四个入口**：`plan`/`gen`/`seg`/`build` —— 坏清单**连规划都不给**（这条是负控逼出来的：我第一版漏挂 `plan`）。
**成片指纹已挂进 build 尾部**：每次出片自动落 `<成片>.fingerprint.json`。

## 四、十条关键点逐条对账（有 / 半 / 缺）

| # | 关键点 | 我们 |
|---|---|---|
| 1 | 节点寻址必须版本化 | 🟡 **换形**：无 ComfyUI 节点 ID ⇒ 我们用**清单字段契约**（specguard）+ 工具链 hash 进指纹 |
| 2 | 显存是唯一硬约束，群控显存感知 | 🟡 **换成内存/配额**：内存压强派单制 + `--batch` 负载闸；显存不适用（无本地大模型） |
| 3 | 幂等与断点续跑 | 🟡 **半个**：`gen`/`seg` 已"存在即跳过"（弱幂等）；**缺** request_id↔内部 id 映射表 + 状态机（Queued/Gated/Running/TimedOut/EnvBlocked/Retrying） |
| 4 | 一致性锚点（LoRA/IP-Adapter/参考图库 · seed 族） | 🟡 **seed 族已补**；**缺**角色资产库（要 LoRA/IP-Adapter ⇒ 得先有云 GPU，见出图源决策） |
| 5 | 音乐板块必须是时间轴权威 | 🟡 **我们有同款判断**（音效床按拍子表打点）；**缺** BPM/段落切分驱动视频裁切 |
| 6 | 评估必须结构化、自动化 | 🟡 `qc` 是机械三项（黑帧/卡帧/亮度）；**缺** VLM 四维打分（构图/一致性/运动/技术缺陷）+ 差异化重试路由 |
| 7 | 版本漂移与可复现 | ✅ **本轮补上**（指纹：清单+工具+引擎+seed） |
| 8 | 成本与时长预算 | ✅ **本轮补上**（预算闸 + 降级动作） |
| 9 | 确认点设计 | ⛔ **缺**：我们的门是安全门与验收门，"低置信度回问"这一格没做 |
| 10 | 能力边界显式化 | 🟡 **半个**：registry 有 `desc`/`safe`，**缺**「能做/需降级/不能做」三级字段（我们的"未验账"是文档级，不是字段级） |

## 五、路线（按它的 P1–P5 映射到我们的件）

| 它的阶段 | 我们的动作 | 现状 |
|---|---|---|
| P1 能力契约化 | 185 位已在册 + 契约测试；**补：能力边界三级字段（#10）** | 90% |
| P2 Spec 化 | **本轮**：specguard（清单强 Schema + fail-fast） | ✅ |
| P3 DAG 编译 | **缺**：把线性拍子表升成 DAG（并行拍/依赖场次）+ 编译确定性（同 Spec 两次编译同一 DAG） | ⛔ 待做 |
| P4 闭环评估 | **缺**：结构化评估（VLM 四维）+ 差异化重试路由 | ⛔ 待做（要视觉通道，见出图源决策的"反推环未接线"） |
| P5 闸门收敛 | **缺**：可选确认点 + 自动放行阈值可度量 | ⛔ 待做 |

**建议顺序**：P3（DAG，纯本地可做）→ P4（要视觉通道解锁后）→ P5（要 P4 的置信度数据）。
**P1 的补丁（#10 能力边界字段）很小，可以顺手做**。
