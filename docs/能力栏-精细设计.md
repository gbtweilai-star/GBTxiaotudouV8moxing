## 〇 · 交付件（两条腿）

| 腿 | 件 | 谁用 |
|---|---|---|
| **A（优先）官方 APP 里那一格** | `plugins/gbt-capability-bar/**`（宿主半边 `lib/host.js` · 浏览器半边 `lib/client.js` · 包声明 `package.json` · 两份进程外验收 `tools/*.mjs`） | DSH 官方 APP（左栏脚部一格 + 浮层内嵌） |

## 一 · 精细设计五条（逐条给做法）

### ① 一屏可读：240 位按族聚合 30 族，默认只出「族 × 三态计数」

- **默认视图**：30 张族卡（`自动填充网格：minmax(392px,1fr)` ⇒ 1400px 宽下 3 列、10 行）。
  每张卡 = 族中文名 + 域 token + `绑 N · 直 n · 触 m` + **一位一格的点阵**（240 位全在屏上，
  每格 7×11px，点一下看那一位）+ 三态计数（接 N · 断 N · 未探 N）+ 「明细」按钮 + 「详页」按钮。
- **点开才铺条目**：点「明细」在该族卡下方就地展开（`grid-column:1/-1`），**懒构建**（首次展开时才建行）、
  按状态排序（断连 → 接上 → 未探测），每行 = 位名 + 状态 + 绑定 + 链 + 域 + 依据 + 末次 + **调用法**。
- **不许一上来铺 240 行**：默认 DOM 里只有 30 张卡 + 240 个小格（格是 `<i>`，无文字）。
  实测：首屏（1400×900）出 15 张族卡；全页 30 族 + 8 张读数卡共 4 屏，**族盘本身 ≈1 屏**。
- 另给一个**筛选框**（族名/域 token/能力位名，纯前端过滤，不取数）。

### ② 三态一色：接上=品牌青 / 断连=品牌金 / 未探测=品牌紫（+ 图例；**未探测不画成通**）

- **令牌**（唯一一处裸色值，在 `:root`）：`--gbt-gold/--gbt-cyan/--gbt-violet` 三个品牌 token；
  三态各**引用**其中一个：`--cb-on:var(--gbt-cyan)` · `--cb-off2:var(--gbt-gold)` · `--cb-unk:var(--gbt-violet)`。
  **不引第四色**；「缺失」用**同一个金 + 虚线形状**区分（形状不是颜色）。
- **类名唯此一份**：`接上→on · 断连→off · 未探测→unk · 缺失→miss`（`.cb-st-*`；判据 C3 逐条验色：
  接上必须青、断连必须金、未探测必须紫**且规则里不许出现青**）。
- **"未探测不画成通"落到三处**：① 点阵里未探测格用 46% 透明度紫（视觉上就不"亮"）；
  ② 行内徽章文字明写「未探测」+ 为什么（窗口内没见它跑 / 证据源未接）；③ 判据带**负对照**：
  把未探测改成品牌青 ⇒ 立即报红。
- **证据是运行记录，不是"已绑"**（这条是设计的地基）：
  · **接上** = 账本窗口内该位**最后一次**记录是 `ok`；· **断连** = 最后一次是 `denied`/`error`（**原始串随行**）；
  · **未探测** = 窗口内没有该位记录（**不等于坏**，也**不画成通**）。
  「已绑（直连/触手承载）」是**另一栏事实**（绑定台账三边零未绑），两条一起看 ≠ 互相冒充。

### ③ 数据新鲜度：每个数字带来源与时刻（照《数据新鲜度契约》声明形态+时刻，按年龄上色）

- **三源**：`state/cap-bindings.json`（绑定台账）· `state/capability-audit.json`（审计 326 项）·
  `holo_pet_w3/capability-bar/run-evidence.js` / 宿主 `live.js`（运行证据，**窗口口径随行**：
  近 24 小时 · 最多回读 24MB · 是否触顶 · 窗口内记录条数）。
- **每张读数瓦片**都挂一行来源小字（`文件名 · 快照 · Nm 前`），页脚另有一张**来源与时刻表**：
  文件 / 管什么 / 生成或现读时刻 / 年龄 / 重生成（判据）命令。
- **按年龄上色**（快照档，照契约阈值）：**≤6h 青 · ≤48h 金 · >48h 紫**；页面顶栏那枚芯片
  声明的是「**取最旧一源**」的年龄（最新数字也被最旧的输入封顶 —— 保守口径）。
- **声明口**：`window.GBT_DATA={kind:'快照',at:陈旧源时刻}` + `<html data-data-kind/data-data-at>`，
  并调壳体注入的 `window.gbtFresh`（若在）；**宿主里**用 `live.js` 的票面时刻。
- **读盘口的两条如实**：file:// 下页面**不读盘**（没有口）⇒ 记录本/运行时那两行显示
  「（本页不读盘 · 宿主内现读）」，**不虚报时刻**；宿主里由 `live.js` 给现读值与时刻。

### ④ 零打扰：无 emoji 图标 · 无外链图床 · 无裸色值 · 尊重 prefers-reduced-motion

- **无 emoji**：状态一律 CSS 圆点/虚线圆；展开用文字「明细/收起」。判据 C6 用 emoji 区段正则扫全文。
- **无外链**：`src/href` 不许出现 `http(s)://` 或 `//host`（判据 C5 的 `_EXT_RE` 同款）；图只用仓内相对路径
  `../../assets/brand/logo-potato-64.png`（真资产，不重画）。
- **无裸色值**：`:root` 之外一个 `#hex/rgb()/hsl()` 都不许有（判据 C6 剥注释后扫）；三色**声明了就必须被引用**
  （R63 教训）—— 判据同时验"声明在 + 引用在"。
- **动效**：全页唯一动效是顶栏一条 7s 扫描线；`@media (prefers-reduced-motion: reduce)` 下 `animation:none`（判据 C7）。
- **零远端取数**：全文没有那几样取数原语（判据 C5 逐个扫），数据只走同树经典脚本。
- 页面自身**零 iframe**（同族规矩）；浮层里的 iframe 属**插件半边**（`lib/client.js`），不是页面。

### ⑤ 可点到处：每族/每类给「详页」或**调用法**；给不出的明写「无对应页」，**不许死链**

- **通用调用法**（永远给得出）：`py -3.14 -m gbt_allinone run <位名> '{"op":"status"}'`，
  每位一行 + 「复制调用法」按钮（`navigator.clipboard`，被拒就落 `execCommand`，再被拒就明写"手工复制"）。
  判据 C8 校验页面里出现的位名**必须在册**（不许给不存在的能力位写调用法）。
- **详页指针**：清单**唯此一份** `PTR_PAGES = { "energy": …, "capabilities": … }`，判据 C8
  拿 `holo_pet_w3/shell/windows.json` + `panel/index.html::PAGES` **现读两个在册源**校验（死链即红）。
  · 在壳里：点「详页」走**壳自己的口** `window.gbtW3.panelGoto({id})`（把结果如实回写按钮文字，成败都报）；
  · 没有壳口（官方面板/浏览器直开）：按钮文字给出「**控制面板 → 能量与绑定**」这类**文字指针**，**不开新窗、不嵌死链**；
  · 给不出对应页的：按钮明写「**无对应页 · …**」并置灰（本页当前 30 族 8 类都有对应页，该分支为负对照保留）。

## 二 · 与 gbt-master 的关系（加法，不加锁）

| 面 | 结论 |
|---|---|
| 插槽 | 只用**它没占的两格**：`sidebar.footer.action`（id `gbt-capbar`，order **42**，排在它 40/41 之后）+ `shell.overlay`（id `gbt-capbar-layer`，order 41）。品牌两格/会话头**一格不碰** |
| 首页注入 | **不调 `tapIndex`**（避开与它自愈器的双份刷新源） |
| **页面戳** | **绝不写 `documentElement.dataset.gbtGen`** —— 那是它自愈器 `heal.js` 的判据（`stamp() === 宿主现报的 plugin`），写它会把整页判成"旧世代"而触发刷新。本件只写 `data-gbt-capbar`。判据专设一条（`verify-client-apply.mjs` A7）钉住它 |
| 白名单 | 各走各前缀；本件面**窄得多**（1 前缀 + 5 精确文件 vs 它放行整套面板） |
| 自报诊断 | 各存各的内存（`/gbt-capability-bar/diag` vs `/gbt-master/diag`） |

**观察（只记录，一件未动）**：`plugins/gbt-master/lib/heal.js` 的 `mounted()` 判 `.gbtm-gv`，
而该 class 在其 `lib/client.js` 里只出现在 CSS 段（v9 已删带该 class 的按钮）⇒ 若非我漏看，
自愈条件 `stamp()===gen && mounted()` 可能**恒假**（页面最多被刷 3 次后停在限额）。
**这属 gbt-master 的件，本件不改**；改动点建议：把 `mounted()` 改判当前代 bundle 会打上的东西
（如 `[data-gbt-capbar]` 之外的自家键，或它自己的 `#gbt-potato-master-v9-style`）。
