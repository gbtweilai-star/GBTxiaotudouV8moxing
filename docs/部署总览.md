## 四、要主人做的：只有一步

1. 双击桌面 **「部署APP」** → 窗口里**手打三个字母 YES 再回车**（共三次：`deploy_publish` /
   `process_execute` / `filesystem_write`，一次性、10 分钟有效）；回车＝取消。
2. 只想要一次 YES：同窗口改成跑 `--master`（只讨一条 `owner_control` 总控，
   按声明可替代该次动作所需的全部未授权作用域）：

```
cd C:\Users\ADMIN\Desktop\GBT小土豆V8
py -3.10 deploy_app_oneclick.py --master
```

3. 或在自己的 PowerShell 里（连 YES 都不用输，走主人本机会话）：

```
cd C:\Users\ADMIN\Desktop\GBT小土豆V8
$env:GBT_OWNER_SESSION=1; py -3.10 deploy_app_oneclick.py --owner
```

跑完**自动**产出：

- `部署结果.md` —— 给人看的结果交代（版本号 / 文件数 / 耗时 / 成败原因）
- `.scratch/_deploy_app_last.json` —— 机器读的结果账

## 五、两处根因 · 已修（R-H98，2026-09-19 11:xx）

1. **`owner_control`（主人总控授权）从纸面变成真能力**：此前全仓只有两行描述字符串、
   没有任何代码读它。现按它自己的声明实现：本次动作缺件时，**一条总控顶掉这一次**
   （一次性消耗，审计记 `substituted_for`，并透传到调用方）；有对应授权时总控不动。
   配套加了硬约束测试：两张作用域表必须**逐字一致**（历史漂移就是"同义不同文"来的）。
2. **能力入参契约立起来了**：注册表新增 `PARAM_REQUIRED`（16 项，每条都有处理器出处），
   `all_caps()` 把契约带出去；面板侧缺参**当场如实拒绝**（不跑、不猜），前端给这类能力标
   `✎ 需参数`、点一下只告诉你缺什么，不再发 `{}` 空调用。契约不是越写越严——实测发现
   `devour_pulse` 空调用本就能跑，**已按事实从名单里撤掉**。
3. 还剩半步：`panel_server.py` 的拒参逻辑要**面板重启**才生效（前端 `app.js` 已在线生效，
   实测面板发的哈希与磁盘一致）。
