## §0 一句话结论

六类操控面逐格对过了：**五面有路由**（任意 APP / 浏览器 / 可调试 CDP / 蓝牙 / 本机设置面）——
**读类现在就能用（现探）；动手类吃票，而票在 2026-10-08 09:09 由主人发了整机授权（6 个作用域各 1 张，window 模式）**；
**无线网是唯一没有能力位的那格**：可控制键 43 把已探到并已登记进 `surface_bind`，但**执行按键的能力位还没建** ⇒

**麦克风那条腿本机是真没有**（活动录音端点 0）⇒ 离线识别器能听 WAV（**真跑出了文本**）、不能听麦；
启用被禁用的录音设备**只有主人能做**。

## §2 离线语音输入那条腿（能听 WAV · 不能听麦）

### 2.1 接法（一条命令）

```bash
py -3.14 tools/codex-scripts/asr-offline.py status                      # 只读：识别器 / 输入端点 / 口径
py -3.14 tools/codex-scripts/asr-offline.py listen --wav <某个.wav>      # 真识别一个真文件
py -3.14 tools/codex-scripts/asr-offline.py listen --device --seconds 3 # 设备直连（本机必败，原文照贴）
py -3.14 tools/codex-scripts/asr-offline.py selfcheck --json            # 7 条判据 + 变异负对照
```

识别本体**不重写**：仍走仓内唯一的 `tools/codex-scripts/asr-listen.ps1`（`System.Speech` 的 `SpeechRecognitionEngine`，

`asr-offline.py` 只做调度 + 取证 + 判据。
⚠️ `asr-listen.ps1` 用了 PowerShell 7 的 `if` 表达式语法 ⇒ **必须 pwsh**（本机 7.6.6 在位）；
用 5.1 的 `powershell.exe` 会直接解析失败（实测原文：`赋值表达式无效。赋值运算符输入必须是能够接受赋值的对象`）。
