结论：**产出方自报「status=ok」不能当验收**（反面里它放行了假产出）；**独立只读盘的终审能拦**（正反两例都判对）。这就是"验收方 ≠ 产出方"的最小可跑形态。落地闸：`terminal-review.py review` 退出码 0/1；落地留痕：`lr_submit` acceptance + `memory_bank` 印章 + `logbook` 记录。
