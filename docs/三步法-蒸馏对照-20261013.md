## 一、图1 那三行 → 我们的三步（都是现读）

| 图上那一步 | 我们这边的对位 | 现读证据 |
|---|---|---|
| `scan github / cad-agent` | `gbt-vendor-intake` 七步法的**第 1–2 步**（克隆落位 → 只读体检）+ `devour_scan` / `devour_github` | 技能在册 |
| `resolve protocol / mcp` | 我们的接入面是**能力位 / 触手**，不是 MCP 服务器：`surface_bind` / `tentacle_bind` / vendor-intake 第 4–6 步 | 271 位在册 · 触手 10 域 |
| `mount workspace / freecad` | **已在，而且更宽**：`cadgen 0.7.15`（`C:\Users\ADMIN\.local\bin\cadgen.exe`） | `cadgen --version` ⇒ `cadgen 0.7.15` |

**`cadgen` 自带 MCP 出口**（`cadgen --help` 现读）：

```
mcp            serve CAD to an agent host over MCP (stdio)
doctor         print installed cadgen and verify a skill's pin
snapshot       render any supported input to an image
step build     3mf build   glb build   dxf/sdf/srdf validate
```

⇒ 「FreeCAD-MCP」这条链**我们不接**，理由三条（都可复核）：
1. **本机没有 FreeCAD**：`C:\Program Files\FreeCAD*` 与 `C:\Program Files (x86)\FreeCAD*` **两处都现读为无**，PATH 里也没有 `freecad` / `freecadcmd`；
2. **我们自己的宿主已经带 MCP**：`cadgen mcp` 直接把 CAD 通过 MCP 服务给 agent host —— 图里那件事**我们已经有了**；
3. **我们的能力面比它宽**：`step / 3mf / glb / dxf / sdf / srdf` + 快照复盘 + 几何测量 + `doctor` 自检。

> 它剩下的唯一价值是「**FreeCAD 那个 GUI 生态**」。要不要为它装一个几百 MB 级软件换那套界面 ——
> **这是主人的决定**，我不替他拍（装机 = 改本机环境）。
