# 静图 → 成片 端到端证明

> 目的：证明「分镜静图 → 成片」这条链**用真图能跑通**，不是停在"理论可行"。
> 这一环与 ComfyUI **无关** —— 它证明的是**合片那半条链是真的**，
> 等图像来源（ComfyUI / 云端 / 别的）就绪时，这条链**立刻能用**。

## 一件一件的实读

| 件 | 读数 |
|---|---|
| 静图 ×3 | `shot-01.png` 6,078 B · `shot-02.png` 6,186 B · `shot-03.png` 6,078 B（均 1280×720） |
| 出片工具 | `tools/codex-scripts/make-video.py`（Ken Burns / zoompan + xfade） |
| 成片 | `out.mp4` **h264 · 1280×720 · 30 fps · 144 帧 · 4.800 s · 119,859 B**（无音轨） |
| 量片工具 | `ffprobe`（读数由工具回读，不是"ffmpeg 说成功"） |

## 时长账（**这一条以前没点明**）

`--sec` 是**每段**时长，而段间**交叉溶解会吃掉重叠** ⇒ 成片 = `n×sec − (n−1)×xf`：

```
名义 6.000 s（3 段 × 2.000 s）
重叠 1.200 s（2 处 × 0.60 s）
实际 4.800 s  ← 与 ffprobe 的 dur 分毫不差，判据「对得上吗」= true
```
**不按 `n×sec` 期待** —— 这是本轮补进工具的字段。

## 诚实边界

- 本证明**不含任何生成式出图**：帧是 Pillow 画的色块（**不是**模型生成的），
  运动由 ffmpeg 算。它证明的是**链**，不是**画质**。
- 「无限生产高质量电影」的**帧来源**仍缺：见 `state/comfy-surface.json` ——
  **视频模型 0 个** ｜ **内存这一关没过**（空闲 467 MB vs 估峰值 4283 MB，差 3816 MB）。
