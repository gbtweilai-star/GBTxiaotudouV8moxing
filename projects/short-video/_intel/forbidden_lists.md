## 一、三方向共用红线（7 条）

| 红线 | 具体禁止什么 | 出处 |
|---|---|---|
| **不得使用第三方版权素材** | 游戏角色形象 / 影视截图 / 他人音乐 / 上游模板里的示例素材，一律不许当**我们的**产物。本会话已按此判过：《仙剑奇侠传》的角色图**没有**采用。 | 家规第 2 条（`projects/_shared/licenses/manifest.json` 逐件登记）+ `video-pipeline` §6「版权与人物授权完整」 |
| **不得使用真人肖像与声纹（无可追溯授权时）** | 人物一律走**剪影或自产**；要立绘须走自产通道。声纹同此。 | `music-production` §4「样本、声纹与旋律来源可追溯」+ `video-pipeline` §6 |
| **不得留明文凭据** | 密钥、令牌、口令一律不许进任何文档与产物；对外只报「已配 / 未配」或前 4 位掩码。 | 仓规（凭据零明文）+ `cloud_pc` 五闸之 gate_key「明文凭据即拒」 |
| **发布不得绕授权门** | 发布是不可逆外部动作。**模块不接受自带令牌绕门**；提交一律停在主人授权门。 | `media_pipeline.publish` 原文 + `media_publish.submit` 恒 blocked 的实测 |
| **不得把「没量到」念成「通过」** | 空集、量崩、跳过、未验 —— 都不等于合格。判据必须**拒绝空洞的通过**。 | `caps_called_audit` 规则「零调用点的内调型能力位 = 不存在」+ `drama` R2《反假绿律》 |
| **判据里出现数字，就必须有对应的量测步骤** | **不许手写我记得的数字**。数字必须现算、并写清是怎么量的。 | 真件《夜航》第 63–66 行的教训（原写「每行 9–11 字」被审计官实测证伪） |
| **不得编造出处与主张** | 引用外部资料时，每条主张都要能追到**已捕获**的来源；不可验证的**如实标不可验证**。 | `music-production` §1 溯源铁律 + `provenance-discipline` 规程 |

## 二、短视频 专属红线（5 条）

| 红线 | 具体禁止什么 | 出处 |
|---|---|---|
| **不得在视频画面上画东西** | 需要箭头 / 图形 / 原理的镜头，改做**一盏打亮的工作台上的 HTML 动效页**；当「物件」本身是主体时用真 3D 物件。生成视频只留给**必要的连续动作**，字幕是它唯一的文字。 | `video-pipeline` §2.1（上游明写的用户指令） |
| **不得复制别人的选择理由** | 每一个镜头都要有目的：**读旁白 → 写 `shot.render` → 写选择的理由**。**复制别人的理由 = 失败。** | `video-pipeline` §2.2 |
| **「求转发」不算可转发物** | 可转发物 = **一句能原样被转出去的话**（一句话 / 一个数字 / 一个判词）。**求转发是请求，不是可转发物**；缺了分镜板打回。 | `video-pipeline` §5 + 分镜契约填写页 `share_text` 原文 |
| **未知价格不得猜** | 成本闸：预算上限必须先写出来；**未知价格直接失败，不许猜**。没有哪个镜头因为「它在开头」就值得付钱（`hook_video` 默认关）。 | `video-pipeline` §3 + §2.3 |
| **单张静帧不得超时占镜** | 单张静帧最多占一个镜头（`max_static_ground_seconds` 默认 **8s**）。 | `video-pipeline` §3 |

## 本版**不收**的（须出网才能定 —— 留白，不许拿我记得的当红线）

以下四类**本版一个字都没写**，因为它们**需要出网**才能有出处。**留白 ≠ 没问题**：

1. **各发布平台的社区准则**（哪类内容会被下架 / 限流 / 封号）—— 平台条款会变，必须现取。
2. **法律条文**（著作权 / 肖像权 / 邻接权 / 生成内容标识义务）—— 必须引现行法条原文。
3. **第三方曲库与素材站的授权条款**（CC 变体 / 商用限制 / 署名要求）—— 必须逐站现读。
4. **六个维度的调研**（`_intel` 其余五维）—— 本机的 `_intel` 三格**全空 = 未调研**，
   **不是"没问题"**。

> 要补这四块，必须**主人授权出网**。在那之前，**本文件只承载"仓内已有出处"的红线**，
> 并如实标明**它没覆盖什么**。
