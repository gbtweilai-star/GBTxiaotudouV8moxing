# AAA 游戏级画面 · 专业技术蒸馏手册（末班义庄特化版）

## 绝活一：MetaHuman 式数字人标准（UE5 · 04 号文件）

**工业做法**：Epic 的 MetaHuman 把数字人做到电影级——皮肤次表面散射、毛发 groom、面部绑定 52 个 BlendShape（ARKit 标准）。

**对我们的指令**：
- haru 是 Live2D（2D 赛璐璐风）——**不换掉，但用 MetaHuman 的「52 表情标准」当演 oblivion 表**：把 haru 的表情拆成标准 52 项，拍戏时按镜头情绪查表，不凭感觉捏表情；
- 表情幅度纪律：微短剧特写多，**表情幅度比动画小 30%、比真人小 15%**——镜头越近越要收着演（游戏过场动画的铁律）；
- 中期升级位：若 haru 火了，用 MetaHuman 造 3D 版小土豆——**同一人设两个皮**，Live2D 走短视频，MetaHuman 走电影，IP 一鱼两吃。

## 绝活二：高斯泼溅——把真实义庄「搬」进片子（05 号文件 · 1.8 万字）

**工业做法**：Gaussian Splatting = 拿手机绕场景拍一圈视频/照片，算法直接重建出**照片级 3D 场景**，比建模快一百倍，效果是真光影。

**对我们的指令**（《末班义庄》的最大画质杠杆）：
- **实景采集**：找一处真实老建筑（城中村/旧祠堂/仓房），手机绕拍 3-5 分钟 → 高斯泼溅重建 → 义庄场景就有了**真实光影与材质**，AI 生成只能画「像」，泼溅给的是「真」；
- 僵尸与角色（Live2D/AI 生成层）合成进泼溅场景——**真场景 + 假角色 = 恐怖片最经典的可信感**（伪纪录质感就是这么来的）；
- 工具链：Postshot / Nerfstudio（免费）+ 手机，**零成本**，牛马沙箱跑不了（要本地 GPU），归本机触手干。

## 绝活三：虚拟制作流程（06 号文件 · 3.5 万字，本片方法论主轴）

**工业做法**：LED 虚拟制片 = 实时引擎画面当背景 + 实机拍摄合成，所见即所得。

**对我们的指令**（没有 LED 棚，但流程哲学照抄）：
1. **先定「数字布景」再拍**：每场戏开拍前，泼溅场景/生成场景必须先过导演审——背景不确定就不开机；
2. **实时合成**：用 remotion 的分层渲染模拟「背景层（泼溅/生成）+ 角色层（haru/僵尸）+ 前景层（雾/尘/光）」三明治合成——**每层独立可换**，返工只返一层；
3. **相机语言**：虚拟制作的核心是**虚拟摄像机有物理感**——手持抖动、焦点呼吸、变焦惯性。我们的镜头全程序生成，必须给每个镜头写「摄影机性格」；
4. **片场纪律**：一条不过就重拍——数字资产的「重拍」是改参数重渲，成本和真人剧组反过来，**这是 AI 片对真人剧组唯一的不公平优势，用足**。

## 绝活四：AAA 的「画面预算表」（四大件的隐性知识）

游戏公司画质高不是玄学，是**每帧预算花在哪**有铁账。我们的账：
| 预算项 | AAA 做法 | 我们的做法 |
|---|---|---|
| 光 | 全局光照/光线追踪 | 高斯泼溅的真光影 + 后期体积雾（雾是恐怖片最便宜的高级感） |
| 材质 | PBR + 4K 贴图 | 泼溅带真材质；生成图统一喂「胶片颗粒+暗角」后期抹平风格差 |
| 动 | 动捕 + 程序动画 | Move.ai/Wonder 类视频动捕（手机拍人转骨骼）喂僵尸动作——**僵尸的直跳动作用程序生成最正宗** |
| 后期 | ACES 调色 | 统一 LUT（胶片做旧）+ 颗粒 + 暗角（修饰工坊科目已列） |
