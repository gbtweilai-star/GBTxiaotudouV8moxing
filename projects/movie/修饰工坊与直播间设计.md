## 一、修饰工坊：触手吃透手册（视觉与画质是本片的生命线）

**目标**：所有繁琐修饰活，触手必须「吃透到能独立干活」，不许每个镜头都回来问。

### 工坊课程（牛马 + 本机触手分科学习，学完考核）

| 科目 | 内容 | 工具 | 考核标准 |
|---|---|---|---|
| 做旧工艺 | 老录像带质感：噪点颗粒/色偏（褪青留红）/扫描线抖动/磁带横向撕裂/隔行闪烁 | ffmpeg（curves+noise+interlace）、remotion | 出 10 秒对比样片：1986 噪点、1998 VHS、2026 数字三档 |
| 调色分级 | 义庄暖黄 vs 尸变青冷双色调；恐怖片「暗部保留」纪律（吓人的东西在暗处半露） | ffmpeg eq/curves/lut | 同一镜头出三版色，导演盲选 |
| 音效设计 | 赶尸铃（变速=情绪）、尸吼（低频+磁带饱和）、环境底噪（雨/虫/电流） | ffmpeg aevalsrc/混音 | 一场戏完整音轨 |
| 拼接节奏 | 恐怖节拍：静→静→**异响**→静；喜剧节拍：抖包袱后留 0.8s 反应帧 | remotion 时间轴 | 90 秒竖屏混剪一条 |
| 字幕工艺 | 1986 段用硬字幕机风格（白字黑边仿宋）；2026 段用弹幕风 | remotion/ASS | 双风格样片 |

**喂料方式**：本手册 + 资料库随任务发给牛马；本机触手直接吃 `tools/video/*` 源码与 remotion 模板。
**考核官**：导演（框架）盲选样片，过不了回炉。

## 二、电影自动化页 · 直播间款式设计规格（为开源变现预留）

替换 automation 页的电影栏为「**拍摄直播间**」布局（开源后=产品演示间+打赏入口）：

- **主画面**：渲染中的镜头实时预览（大窗）；
- **侧栏·弹幕墙**：观演者发言（开源后=社区互动）；本地阶段显示**产线日志流**（等效弹幕：哪条镜头在渲染、审核双闸判定）；
- **顶栏**：在线人数（本地=触手在线数）· **开播/收工按钮**（=产线启停）；
- **礼物区 → 打赏/赞助**：开源后挂 GitHub Sponsors + 爱发电；本地阶段显示「积分余额」（Genspark 积分/FreeLLMAPI 额度实时读数）；
- **底部播放条**：已成片片段轮播；
- **风格**：与能力球同源深空霓虹，但弹幕区做「老式录像带字幕机」字体——恐怖片直播间，独一份。

**开源变现设计**：核心引擎开源吸星 → 直播间做「AI 拍僵尸片」公开表演 → 赞助+模板付费+定制接单三条进账。

## 三、白龙马蒸馏任务包（等链接）

**现状**：公开渠道查无「白龙马」语音仓库（GitHub 无主流命中；仅抖音 @远远Faraway 有「白龙马 agent 语音功能」演示）。

**你补一个信息即可开工**：仓库链接 / 作者名 / 视频原链接（三选一）。

**链接到手后的蒸馏流程（已备好）**：
1. 牛马抓取：仓库 README + 源码结构 + 语音链路核心文件 → 入 `projects/movie/编剧室/资料库/04-白龙马语音设计.txt`；
2. 蒸馏四问：① 音色怎么定（克隆/预设/多角色）② 情绪怎么控（标签/描述/参考音频）③ 流式与字幕怎么同步 ④ 引擎是什么（TTS 后端）；
3. 提炼落地：对照我们 `voice_orchestra`（多引擎语音中枢，设计同源）逐项比对——**他有的我们抄思路，我们有的补进他没走的路**，最终产出《语音链路融合方案》：小土豆「稍冷少女音+情绪渐暖」直接受益。
