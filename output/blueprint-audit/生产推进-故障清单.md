## 二、`selfscan` 的 3 条审计异常（**都标 legacy，`runtime_faults: 0`**）

```json
{"window": 500, "anomalies": 3, "runtime_faults": 0,
 "by_event":  {"pipeline_blocked": 1, "svc_down": 2},
 "by_signal": {"runtime": 0, "guard": 0, "trace": 1, "legacy": 2, "recovered": 0}}
```
| 项 | 读数 | 念法 |
|---|---|---|
| `runtime_faults` | **0** | 无运行时故障 |
| `anomalies`（窗口 500 条内） | **3** | 1 条 `pipeline_blocked` + 2 条 `svc_down` |
| `by_signal` | `trace 1` · `legacy 2` | **`legacy` = 历史信号**，不是新的运行时崩 |
| `recovered` | 0 | 未标已恢复 |

**🔴 一处必须防的误读**：`errors_by_kind` 那张表列了十几个 kind
（`payment_gateway` · `blockchain_bridge` · `social_trading_v2` · `monitor_service` ·
`backtest_api_v2` · `cis_harvesting_v2` · `quant_api` · `cis_v42_trader` · `crypto_gateway` ·
`gbt_wallet_api` · `gbt_cap_bridge` · `hcl_control` · `gate_daemon` … 各 `legacy: 1`，
`payment_gateway` 是 `legacy: 2`）。
**把 legacy 全加起来远大于 2 ⇒ 那张是「历史累计表」，不是「当前有十几个在故障」。**
**⇒ 当前窗口内的真异常就是 3 条**，不许念成"钱包/链/量化一堆都在坏"。

## 六、第 3 轮：`cross_scan` 收掉了（上一轮标"未验"的那一位），顺出两条真故障

### 6.1 🔴 缺陷：`cross_scan` 空参走**慢路径**，最坏 **24 分钟**，且**没有整体预算**
```
gbt_allinone/cross_scan.py
  153  def _x_run_isolated(kinds=_X_SCANNER_KINDS, timeout_s: int = 240, …)
  189      timeout=timeout_s, env=env      ← 每个子扫描器一个独立子进程，各 240s 上限
  218  except _TimeoutExpired: …           ← 超时只记进子结果，不约束整体
  签名:  scan(deep: bool = True)           ← 有 deep 参数；**空参走 deep=True 慢路径**
```
**实测**：
| 调法 | 用时 | 结果 |
|---|---|---|
| `run_task("cross_scan", {})` | **>560s 未返回**（两次：批内 600s 拖死整轮、单跑 560s 零输出） | — |
| `cross_scan.scan(deep=False)` | **17.9s** | 有实质结果（见 6.2） |

**子扫描器 6 个 × 240s = 最坏 24 分钟。**
**⇒ 任何调它的面板/巡检都会被挂死。** 而**快速路径是现成的**。
**改法（未做，等拍板）**：门面让空参走 `deep=False`，或给整体预算并把"已超"如实报出来。

### 6.2 `cross_scan` 自己报出的实质发现（`deep=False`，17.9s）
```json
{"ok": true, "verdict": "clean", "hard_findings": 0, "latent_only": true,
 "findings": [
   {"dim":"W","issue":"家根影子子目录（与 gbt_allinone/ 同名）: deploy","exposure":"latent"},
   {"dim":"W","issue":"家根影子子目录（与 gbt_allinone/ 同名）: docs",  "exposure":"latent"},
   {"dim":"W","issue":"家根影子子目录（与 gbt_allinone/ 同名）: store", "exposure":"latent"},
   {"dim":"W","issue":"家根影子子目录（与 gbt_allinone/ 同名）: tools", "exposure":"latent"}]}
```
**⇒ 4 条「家根影子子目录」**（家根下与包内同名的目录）标 `exposure=latent` —— **潜在暴露面**，不是硬故障（`hard_findings: 0`）。

### 6.3 又一处该照抄的口径（它自己写的）
```
dims_implemented: [A,B,G,W,X]      dims_unimplemented: [D,E,F,V]
coverage_note:「本扫描有实现的维度 5 个；另有 4 个维度【只有名字、没有实现】，
               已从 dims 中剔除 —— 不许把「声明过」读成「扫过了」。」
```
**⇒ `cross_scan` 的"clean"只覆盖 A/B/G/W/X 五个维度；D/E/F/V 四个维度是空的。**
这与 `selfscan` 的 "sampled 58.8%"、`truth_scan` 的 "副作用类未验证" 是同一种诚实：
**本仓的体检口自己会声明覆盖面，读的人不许把"通过"读成"全覆盖"。**
