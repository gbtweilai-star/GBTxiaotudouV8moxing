## 一、真 SileroVAD（ONNX 权重，不碰 torch）

### 1.1 先量模型契约，不猜

`gbt_allinone/store/models/` 6 个权重**逐个建真会话**量出入参（`.scratch/_onnx_io.py` 实测输出）：

| 权重 | 字节 | 真实契约 |
|---|---|---|
| `silero_vad.onnx` | 2,327,524 | `input[None,None]` + `state[2,None,128]` + `sr` → **stateful_sr（最宽）** |
| `silero_vad_16k_op15.onnx` | 1,289,603 | stateful_sr |
| `silero_vad_op18_ifless.onnx` | 2,845,718 | stateful_sr |
| `silero_vad_half.onnx` | 1,280,395 | stateful_nosr |
| `silero_vad_openvino_16k.onnx` | 1,288,203 | **fixed_window `[1,576]`** |
| `silero_vad_16k_sequence.onnx` | 1,246,165 | lstm_sequence（逐窗接口不适用） |

关键旁证：openvino 版把窗口**写死成 576** —— 576 = **64 上下文 + 512 新样本**，
与 Silero 官方窗一致。跳 512 ⇒ **32 ms/帧 @16k**。

### 1.2 端到端实测（真语音，不用麦克风）

用 SAPI 把文字**合成到 WAV 文件**（不占声卡、不联网）当"真语音"样本：

| 输入 | 帧数 | max 概率 | mean |
|---|---|---|---|
| 数字静音 1.0 s | 31 | **0.0089** | 0.0047 |
| SAPI 真语音 5.24 s | 163 | **1.0000** | 0.6947（112/163 帧 > 0.5） |

起音曲线干净：`0.002 → 0.017 → 0.021 → 0.150 → 0.844 → 0.985 → 0.991 → 0.998 → 1.000`
**两次跑逐帧一致**（确定性）。

### 1.3 落地物

  engine_info`，权重优先级按**实测契约宽度**排（不按文件名想当然）。
- 触手新增两法：`audio_vad_silero`（含现抓回环再判）/ `audio_vad_models`。
  **触手方法数 131 → 133**（10 域不变）。
- 引擎缺失时返回**结构化拒绝**（`unavailable=True / denied=False / rule / missing / fallback`），
  指向 `audio_vad_energy`，**绝不悄悄降级成能量法冒充神经网络**。
- `AUDIO_GAPS` 两处**过期假声明**一并改正：
  - 原「无流式、无实时打断（barge-in）」—— 而 `audio_stream` / `audio_barge_in` 早已落地；
  - 原「VAD 是轻量的，不是 SileroVAD」—— 已有真 SileroVAD。

## 二、稳定化的根因：一个类别，不是三个 bug

全量回归起初**跑不完**：单测 30 s 硬超时把整个进程杀掉 ⇒ **连判决都没有**。
顺着超时栈一台台量，全部同族：**走全树、不剪枝**。

| 扫描器 | 改前实测 | 改后实测 | 修法 |
|---|---|---|---|
| `test_api_probe._ProbeCallScanner` | **42.12 s** / 5216 文件 | **8.0 s** | `rglob` 先走遍全树（吐 10549 个 .py / 3.99 s）→ 改 `os.walk` **进子目录前剪枝**（639 个 / 0.05 s） |
| `caps_called_audit.audit()` | **33.21 s**（抖动 19.5–33.2） | **1.98 s（16.8×）** | 141 能力位 × 275 文件 = **38,775 次正则**各扫全 4.4 MB → 先把语料切词表再 O(1) 查 |
| `gate_visibility.scan()` | 走不完（30 s 超时） | 约 0.3 s 级 | 收敛到唯一口径 + 被排除语料**各占一行** |
| `quant_tech.platform_profile`（**生产路径**，非测试） | 挂死 | **0.23 s** | `WS.rglob("*.py")` → 剪枝走法，并**报出被排除量** |

### 2.1 两处"假排除"（比不登记更坏）

- `test_api_probe.SKIP_DIRS` 里写的是 **`".pylibs"`（带点）**，**永远匹配不上 `vendor/pylibs`（不带点）**
  —— 实测 `vendor/pylibs` **3106 个 .py / 42.5 MB** 一直在被啃。**看着登记了、其实登记错名。**
- `os.walk` 默认**静默吞掉** scandir 错误 ⇒ 没贴标签的天窗。已改为 `onerror` 记账 + `OSError` 也计入
  `parse_errors`（实测本仓存在 `PermissionError` 的 `.py`：`store/pipeline/.../.versions/run.py`）。

### 2.2 收敛成唯一口径

新增 `gbt_allinone/tools/scan_scope.py`：**扫描范围唯一口径**
（`EXTERNAL_CORPORA` 带≥15 字理由 / `TOOLING_DIRS` / 剪枝 `walk` / `iter_files` / `corpus_sizes`）。
`test_api_probe` 与 `gate_visibility` 的**私有名单作废**，改从这一份取 —— 同一份名单被抄三遍，
就会有三份各自过期的名单。

被排除的语料**贴标签 + 报尺寸**（可数出来才叫声明）：

| 语料 | .py | 体积 | 理由 |
|---|---|---|---|
| `vendor` | 3106 | 42.5 MB | 第三方 vendored 依赖，非本仓编写 |
| `_upstream` | 889 | 9.2 MB | 外部上游仓原样停放区，供蒸馏参考 |
| `.shadow-repo` | 627 | 7.6 MB | 本仓影子镜像副本，扫它把同一处数两遍 |

剪枝后**仓内 .py = 640**。

### 2.3 等价性证明（改性能必须自证没改语义）

`caps_called_audit` 是**只读审计读数**，所以改法必须与冻结基线逐字节一致：

```
基线（改前）audit() = 33.21 s · 41,414 B · sha256 056C7A4154F21956
改后        audit() =  1.98 s · 39,708 B · sha256 A9A20735342563EB
归一化行尾后逐字节一致 = True      ← 差 1,706 B = 1,706 个 \r\n（基线是文本模式写的，**我的比较口径错**，不是代码不等价）
解析后对象相等 = True · 逐字段差异 = 无 · wired 名单一致 = True · 每个 wired 的 callers 一致 = True
wired=141 / orphan=0 / scanned_files=275（三者改前后相同）
```
