## 1. 逐件审查（按仓规五问：要密钥？破坏性命令？外传数据？改系统配置？伪装指令？）

### ① HyperFrames（heygen-com/hyperframes）· **建议装（最优先）**
- **许可**：Apache 2.0 ✓ · **要求**：Node ≥22 ✓（本机 v24.15）· FFmpeg ✓（本机 8.1.2）
- **做什么**：把 HTML+`data-*` 时间属性 交给 headless Chrome 逐帧 seek，FFmpeg 编码 ⇒ **确定性 MP4**（同输入同输出）
- **要密钥**：❌ 不要（本地渲染；云渲染/lambda 为可选项）
- **破坏性**：❌ 无（`npx hyperframes init/lint/preview/render`）
- **外传**：❌ 无（除可选云渲染）
- **改系统**：⚠️ 装 node 包到项目目录（正常依赖安装）；文档提到 Git LFS 仅用于其**开发**仓库基线，我们用 CLI 不受影响
- **判定**：**安全**。与我们既有 doctrine 完全同构（本仓 `渲染进化内核设计.md` 已把它列为"确定性"原语、状态"待接"）。

### ② Remotion（remotion-dev/skills）· **建议装（技能包，无代码风险）**
- **装的是**：**Agent Skills（文档/最佳实践）**，不是引擎本体 ⇒ 风险极低
- **许可**：⚠️ Remotion 本体是 **Source-available Remotion License（非自由许可）**，公司规模有商用阈值 —— **要商用请先确认**
- **要密钥/外传/改系统**：❌ 无
- **判定**：**技能包安全**；引擎商用许可需你点头。

### ③ video-use（browser-use/video-use）· **建议装（开源，但需一个付费 Key）**
- **许可**：100% 开源 ✓ · 依赖：ffmpeg ✓（已有）、`uv`（需装）
- **要密钥**：✅ **ELEVENLABS_API_KEY**（转录用；存放在**本地 `.env`**，不外传）
- **破坏性**：⚠️ 会**注册到 agent 技能目录**（`~/.claude/skills/video-use` 或 `~/.codex/skills/`）+ `uv sync` 装依赖 —— 属预期行为
- **亮点（与我们 doctrine 同源）**：**"LLM 不'看'视频，而是'读'视频"**（12KB 文本 + 按需 PNG）· 每刀边界**自评估**（跳切/爆音）后再给你看
- **判定**：**安全，但会引入 ElevenLabs 付费依赖**；可先只装**本地转录替代**（whisper 本仓已有 `openai-whisper` 技能 ✓）规避付费。

### ④ videocut-skills（成峰）· **暂不建议装（硬阻塞）**
- 它自己 README 明写：**新工作台 Skill 要求 Runtime ≥0.5.9，而当前公开下载是 v0.4.11，不满足** ⇒「缺能力时只报告并停止」
- 安装路径依赖 **Codex CLI 的 `codex plugin` 命令**（本机是 DSH，不是 Codex 宿主）✗
- 隐私/安全：无异常；但它会 clone 固定提交并准备独立 Runtime（体量与面都大）
- **判定**：**先不装**（等其 Runtime 达标 + 确认是否愿意引入 Codex 宿主依赖）。

### ⑤ Generative Media（素材）· **已具备**
- 本仓现有：`autoglm-generate-image` · `autoglm-generate-image-seedream` · `autoglm-remove-bg` · `autoglm-search-image` · `autoglm-image-recognition` ✓
- **判定**：**无需新装**；若要"素材 OS"级能力，HyperFrames 自带的 `/media-use` 技能可覆盖（随 ① 一并来）。

### ⑥ Seedance Art（创意）· **已具备规程**
- 本仓：`gbt-arkcli`（规定调用前缀 + 两道闸 + 计费纪律）+ `arkcli-gen`（Seedream/Seedance：图同步、视频给 task_id 轮询）
- ⚠️ **计费动作**：按 `gbt-arkcli` 规程须**先报价、等你确认**再调
- **判定**：**无需新装**；用前需确认已登录 + 账号验证闸 + 你有额度。

## 2. 结论与建议动作（等你一句话）

| 顺序 | 动作 | 命令 | 前置 |
|---|---|---|---|
| 1 | 装 **HyperFrames 技能 + CLI** | `npx hyperframes skills update`（非交互，装核心集） | Node ✓ FFmpeg ✓ |
| 2 | 装 **Remotion 技能包** | `npx skills add remotion-dev/skills` | 无（商用许可另议） |
| 3 | 装 **video-use**（可先不配 ElevenLabs） | `git clone https://github.com/browser-use/video-use` + `uv sync` | 需装 `uv` |
| 4 | 不装 videocut（待其 Runtime 达标） | — | — |
| 5/6 | 素材与创意：**复用本仓已有** | `autoglm-generate-image*` / `arkcli-gen` | 授权与额度 |

**装完之后的"整条流程自动完成"**（对应封面那句话）：
```
素材(autoglm/seedream) → 创意(arkcli-gen / Seedance) → 剪(ffmpeg 或 videocut)
      → 动效(HyperFrames HTML→MP4) → 批量(Remotion 模板) → 精修(video-use EDL+自评估) → 成片
```
我会把这条链落成**单编排器 + 阶段门**（与数字人那条同一套做法：契约/门/账本/模型无关）。
