## 二、落地：病因钩子 `tentacle/nav_etiology.py`（新）

**八类命名病因**（枚举，不是自由字符串 —— 自由字符串只是把"没记录"换成"记了但不可比"）：

| 病因 | 中文 | 重试策略 |
|---|---|---|
| `element_not_found` | 目标元素不在当前画面/树上 | 先滚动或展开再找；换文字特征重找，别原地重试 |
| `window_lost` | 目标窗口已消失或句柄失效 | 重新枚举窗口；必要时重新拉起目标程序 |
| `timeout` | 等到超时仍不满足条件 | 拉长超时或改判据（等状态而不是等固定秒数） |
| `modal_blocked` | 被弹窗/遮罩挡住 | 先关弹窗（ESC/确定）再重发动作 |
| `denied_by_gate` | 被授权门或权限拒绝 | **不许绕门**：如实上报缺哪个 scope |
| `backend_unavailable` | 后端/依赖不可用 | 换后端或先补依赖；**不是重试能解决的** |
| `stale_target` | 元素取到过但已失效 | 重新取一次元素，别复用旧引用 |
| `action_no_effect` | 动作发了看不出效果 | 做前后对比截图确认到底动没动 |

提供的面：`classify` / `evidence_of` / `cause` / `record_swallow` / `enrich` / `etiology`(装饰器) /
`ledger` / `stats` / `clear` / `selftest`。
纪律：**判不出就给 `action_no_effect`，不猜更漂亮的病名**；记录本身包在 try 里，绝不许把执行弄崩；
`ok:True` 路径**逐字节不变**。

**两把对照**：八类病**每类都判得出**（8/8）+ 负对照（成功路径不许被碰、不许进账）⇒ 都过 ✅

## 四、我自己制造并当场修掉的两个 bug（重点留档）

### bug 1：**假收口**（比 bug 2 严重）

第一版我把 shim 插在 `sys.path.insert(触手目录)` **之前** ⇒
`from nav_etiology import record_swallow` 在**导入期**就失败 ⇒ 静默退回本地垫片 ⇒
**63 处"收口"一个病因都没真记上**，而表面读数写着"收口 63 处、剩余裸 print 0"。

**这正是我这两天一直在骂的那种假绿：流程走了、数字好看、事情没发生。**
判别它只需一问：`_record_swallow.__module__` 是 `nav_etiology` 还是退回的垫片？

修法：撤掉两个错位 shim，改成一个**放在 `sys.path` 修正之后**的合并 shim。复验：

```
nav_etiology 已加载 = True
omni_read/omni_mouse/omni_domain/omni_core/omni_window/omni_web/omni_fs/omni_audio
    _record_swallow ← nav_etiology      ← 8/8 都是真身，不再是垫片
```

### bug 2：把触手**改到导入期就炸**

`omni_read.py` 的 `@_etiology(...)` 挂上了，但 `_etiology` 的 import shim 没落成
⇒ `NameError: name '_etiology' is not defined` ⇒ **整个触手 import 不来**。
修完后回归复绿。

### 顺带一条我自己的低级失误

验活体的脚本里又犯了双引号嵌套（`print("…"哪类病最多"…")`）⇒ SyntaxError。
