## 2. 🔴 照规范改掉的两处**错误**（不是补充）

### 2.1 编码判定：缺了 BOM 这一级，且让 meta 越级

**我原来写的**：
```
Content-Type 的 charset  →  （拿不到）正则找 <meta charset>  →  utf-8
```
**规范要求的优先级**：
```
① BOM sniff（certain，压过一切，命中后**丢掉 BOM 字节**）
② 传输层 Content-Type charset（certain）
③ meta prescan（tentative，且**只看前 1024 字节**）
④ 兜底
```
问题有两处：**BOM 这一级整个缺失**；**meta 与 HTTP 头被平级了**，而标准里传输层是 certain、meta 只是 tentative。

**已改**，并新增 `charset_source` 字段把"是哪一级定的"报出来 —— 出乱码时能直接定位到级。
另外 meta prescan 照规范实现了两开关语义：`http-equiv="content-type"` ⇒ got pragma；
`content` 里的 charset 只有 got pragma 为真才算数；`charset` 属性**绕开**这个开关（优先级更高）；
属性名**先去重、先出现者胜**；UTF-16 标签在文档内一律改判 UTF-8；`x-user-defined` → windows-1252。

### 2.2 重定向：**stdlib 默认不跟 307/308** —— 我此前是过度声称

`urllib` 的 `HTTPRedirectHandler` **不会**为 307/308 生成新请求，会当成错误抛出来。
我上一版直接用它，却对外写着"跟随重定向" —— **遇 307 就会失败，那是过度声称。**

**已改**：自己实现重定向循环（`_NoRedirect` + 显式跟），顺带把三件事做对：

- **307/308 也跟**（GET-only 抓取器里方法改写不体现，但状态码与跳链如实记录）；
- **自己定跳数上限**（默认 8）—— RFC 9110 **没有**规定上限，5 跳是已废止的 RFC 2068 建议，
  所以报错文案里**明写"这个数是我们的纪律、不是规范要求"**，别让人误以为有规范依据；
- **自己防环** —— RFC 只要求 "SHOULD detect and intervene in cyclical redirections"；
- `Location` 按规范**相对当前请求 URI** 解析。

## 3. 新增：`web_robots()` —— 抓取礼仪（RFC 9309 全文）

### 3.1 最容易被写错的那条：**非对称**默认

| 取 robots.txt 的结果 | 规范要求 | 我们的实现 |
|---|---|---|
| **2xx** | MUST 遵守解析出的规则 | ✅ 遵守 |
| **4xx（Unavailable）** | **MAY access any resources（放行）** | ✅ 放行 |
| **5xx / 网络错误（Unreachable）** | **MUST assume complete disallow（完全禁抓）** | ✅ **fail-closed** |
| 重定向 | SHOULD 跟 ≥5 跳（可跨 authority）；>5 MAY 视为不可用 | ✅ 默认 5 跳 |

> 这条不对称写错的代价是"**该禁的照抓**"，所以专门有两条用例分别钉住 4xx 与 5xx。

### 3.2 其余照规范实现的点

- **同名 user-agent 的多个组必须合并**（规范 MUST）—— 不是最长匹配、不是只取第一组；
  **最长匹配只用于路径**，按**八位组数**，等长时 **allow 胜**；
  组内无匹配 ⇒ 放行；`/robots.txt` 隐含放行；无匹配组则用 `*` 组；连 `*` 都没有 ⇒ no rules apply。
- 通配：`*` = 0..n 任意字符（**含 `/`**）、结尾 `$` 锚定、其余按字面量；
  注释 `#`（整行/行尾）；规则出现在任何 `user-agent` 之前 ⇒ 不属于任何组，忽略。
- **缓存 24 小时**（规范 SHOULD NOT 超过）；**解析上限 512 KiB**（规范 MUST ≥ 500 KiB）；
  robots.txt 按 UTF-8 解。
- **产品 token = `GBT-Xiaotudou`**，并已放进 UA 串（规范 §2.2.1：token 只允许字母/下划线/连字符，
  且 SHOULD 是 UA 串的子串）—— 抓取要**报得出名号**。

### 3.3 查不到就不编（如实标注）

| 项 | 情况 | 我们的处理 |
|---|---|---|
| `Crawl-delay` / `Request-rate` | **RFC 9309 全文 0 次命中** | **不实现**（不按 RFC 实现不存在的东西） |
| `Disallow:` 空值的匹配语义 | RFC 只给了编码形式 `empty-pattern = *WS`，**没给判定规则** | 显式选业界惯例「空值不构成限制」，并在代码里**注明这是我们的选择、不是规范** |
| RFC 级重定向最大跳数 | **没有规定** | 自己定 8，文案里声明是我们定的 |

### 3.4 默认行为

`web_fetch(..., honor_robots=True)` —— **默认先问 robots**，被禁就如实拒绝并把理由带出来：

```
{"ok": false, "stage": "robots", "error": "robots.txt 不允许抓这个路径：…", "robots": {...}}
```
调用方显式传 `honor_robots=False` 才跳过，且返回值里会记 `robots.decision = "skipped"` —— 不留暗路。

## 4. 实测证据

```
用例：59 passed in 13.06s
  test_omni_web.py  ... 41 passed   （读网域：自适应 26 + 规范级 15）
  test_omni_fs.py   ... 18 passed   （文件域）

真出网复验（robots 闸一起走）：
  example.com ok=True status=200 bytes=559 charset=utf-8(来源 default)
  robots 判定  = allow | HTTP 404 = Unavailable ⇒ 规范：MAY access any resources（放行）
  重定向 history = []
```

规范级用例逐条对应条款，例如：

- `test_robots_5xx_means_complete_disallow` —— 5xx ⇒ 完全禁抓（fail-closed）
- `test_robots_4xx_means_allow` —— 4xx ⇒ 放行（与 5xx **相反**）
- `test_robots_groups_with_same_agent_are_merged` —— 同名组必须合并
- `test_robots_longest_octets_wins` / `test_robots_allow_wins_on_tie`
- `test_bom_beats_transport_and_is_stripped` —— BOM 压过传输层，且**BOM 被丢掉**
- `test_transport_beats_meta` —— meta **不许越级**压过 HTTP 头
- `test_meta_beyond_1024_bytes_is_ignored` —— 1024 字节之后的 meta 不算数
- `test_follows_307_and_308` —— stdlib 不跟的，我们自己跟
- `test_redirect_cycle_is_detected` / `test_redirect_hop_limit_is_ours_and_declared`

## 5. 本步又抓到我自己一个错（测试写错，不是代码）
