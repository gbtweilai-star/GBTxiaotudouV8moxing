## 一、先立事实：大脑执行层的真实结构（全部实测，不是印象）

### 1.1 核心：五维合一（`gbt_allinone/brain_exec.py`）

AST 读出的公开函数**恰好五个**，与注册表里的五个能力一一对应：

| 维 | 函数签名 | 注册能力 | 注册表原文说明 |
|---|---|---|---|
| **路由** | `route(intent)` | `brain_route` | 意图→能力动态路由（语义匹配+备选建议） |
| **执行** | `execute(...)` | `brain_execute` | 单能力直调或多能力并行（**万能插线程池**） |
| **验证** | `verify(expectation, window)` | `brain_verify` | **触手肉眼验证现实**（视觉指纹 + UIA 穿透读回） |
| **健康** | `health()` | `brain_health` | 五维自检评分（路由/执行/触手/视觉/审计） |
| **合一** | `unify(...)` | `brain_unify` | route→execute→verify→health 一条链 |

**路由表实测**（`api.py`）：
```
brain_route  -> brain_exec.route(intent)
brain_verify -> brain_exec.verify(expectation, window)
brain_health -> brain_exec.health()
brain_unify  -> (五维链)
```

### 1.2 同层的能力（域 = llm / mind / tentacle）

| 能力 | 域 | 说明 |
|---|---|---|
| `think_loop` | llm | 推演环：理解→镜像推演→调工具→自纠→反向延伸→反思→整理 |
| `autopilot` | llm | 自主编排环：目标→LLM拆解→本地校验→执行→自检→修复（轮数上限防失控） |
| `llm_chat` | llm | 操控其他 AI（DeepSeek/Kimi/OpenAI 密钥链自动路由） |
| `mind` | mind | 心智引擎：开工前预演、评估、内部状态、经验召回与反思 |
| `brain_vault` | mind | 脑库：Obsidian 记忆读/写 |
| `tentacle` | tentacle | 触手/眼/手：给意图自动命中方法 |
| `local_brain` | — | **只读骨架**：不加载模型、不起服务、不出网、不落盘 |

## 二、要画成什么样（专业设计的四条判据）

「细节决定未来」⇒ 每一条视觉元素都必须**承载信息**，装饰不许无意义。

1. **一眼看出层级**：核心层（五维）≠ 同层能力 ≠ 底座支撑 ≠ 触手效应器。四层靠**位置 + 体量 + 明度**区分，不靠颜色乱标。
2. **一眼看出流向**：`unify` 的链是**有向**的（route→execute→verify→health），必须能看出"从哪到哪"，与能力球已做的**尾迹画法**复用同一套视觉语法（起点暗→终点亮 + 硬芯）。
3. **一眼看出状态**：每一维实时显示**通 / 忙 / 卡**（数据从真实调用来，不许编）。这与能力球的 `HEAT` 同源。
4. **放大不糊**：芯线用"外软内硬"，必要时超采样（`deviceScaleFactor=2`）。这条已写入能力球的实现，直接复用。
