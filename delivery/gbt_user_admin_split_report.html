一、管理端隔离（零泄露）

公网唯一入口 8097。12 个内部端点（引擎任务、运营审核、管理员注资、订单内部视图、结算）全部挂 Bearer 门禁——未配置管理员令牌时用进程内随机值，公网不可入。

端点类别数量公网实测

架构原则：内部服务端口（8094 兑换 / 8081 支付 / 8085 监控等）从不直接暴露，用户端全部走 8097 白名单同源代理。
