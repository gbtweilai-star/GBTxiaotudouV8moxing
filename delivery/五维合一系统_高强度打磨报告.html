二、打磨中发现并修复的真 Bug（2 个）

🐛 Bug 1：万能插守护进程缺 socket 导入
  • 现象：所有守护进程操作直接 NameError: name 'socket' is not defined
  • 根因：文件头声明了 dynamic-import，但独立运行时未真正 import socket
  • 修复：补 import socket，压测立即 100% 通过
🐛 Bug 2：熔断器触发后永久冻结（死锁）
  • 现象：熔断触发后即使系统空闲也永不恢复，新指令永远被拒
  • 根因：延迟样本只在指令出队时记录，队列排空后不再有新样本，平均值永远冻结
  • 修复：trip 后若所有项目空闲 >3 秒，自动清空延迟窗口并恢复
  • 验证：能拦截（积压后新指令被限流）→ 能自愈（空闲后新指令放行）
